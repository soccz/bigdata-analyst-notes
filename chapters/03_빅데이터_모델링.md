# 3과목: 빅데이터 모델링

## 📋 과목 개요 & 출제 경향

**한 줄 요약**: 1과목에서 수집하고 2과목에서 탐색한 데이터를, 실제 분석 모형으로 만들어서 예측/분류하는 과목이다.

**출제 비중 높은 주제**:
- 회귀분석 (선형회귀, 로지스틱회귀, 규제회귀) -- 매회 1~2문제
- 의사결정나무 (지니지수, 엔트로피 계산 포함) -- 매회 출제
- 인공신경망 (활성함수, 역전파, 과적합 방지) -- 매회 1~2문제
- 앙상블 (배깅/부스팅/랜덤포레스트) -- 매회 1~2문제
- 군집분석 (K-means, DBSCAN, 덴드로그램) -- 매회 출제
- 시계열분석 (ARIMA, 분해시계열) -- 매회 1문제
- 연관분석 (지지도/신뢰도/향상도 계산) -- 매회 출제
- SVM, 딥러닝(CNN/RNN), 오토인코더 -- 최근 출제 증가 추세

**시험 팁**: 이 과목은 알고리즘이 많다. 각 알고리즘의 (1) 핵심 원리, (2) 장단점, (3) 하이퍼파라미터가 무엇인지를 중심으로 정리하면 대부분의 문제를 풀 수 있다.

### 알고리즘 진화 흐름도 (전체 맥락을 먼저 잡자!)

아래 흐름을 머릿속에 넣고 각 장을 읽으면 "왜 이 알고리즘이 나왔는지"가 자연스럽게 이해된다.

```
[선형회귀] "수치 예측은 되는데, 분류(0/1)는?"
    ↓
[로지스틱 회귀] "분류 OK! 하지만 직선적 경계만 가능..."
    ↓
[의사결정나무] "비선형도 OK, 해석도 쉬움! 하지만 과적합이 심함..."
    ↓
[앙상블(랜덤포레스트/부스팅)] "나무 여러 개를 합치면 과적합 극복!"
    ↓
[SVM] "마진 최대화로 강력한 분류! 커널로 비선형도 해결!"
    ↓
[인공신경망/딥러닝] "데이터가 충분하면 어떤 패턴이든 학습 가능!"
    ├─ [CNN] "이미지 특화"
    ├─ [RNN→LSTM] "시계열/텍스트 특화"
    └─ [트랜스포머] "어텐션으로 병렬처리, 현재 최강"

별도 흐름:
[군집분석] 정답 없이 그룹핑 (비지도학습)
[연관분석] 장바구니 패턴 발견 → [FP-Growth] 트리 기반으로 효율 향상
[시계열분석] 시간 흐름 예측 → [지수평활법] 최근 데이터에 가중치
[텍스트분석] TF-IDF → [토픽모델링(LDA)] 숨은 주제 발견
[생성모델] 오토인코더 → [GAN] 생성기 vs 판별기 경쟁

회귀분석 확장:
[단순/다중 회귀] 선형만 가능 → [다항회귀] 곡선도 가능
[변수 많고 공선성] → [PCR] PCA 후 회귀 → [PLS] y도 고려해서 성분 추출
```

         /        \       /      \      |           |
      [적음]    [많음]  [예]   [아니오] |        [PCA]
        |         |      |       |     [K 아는가?]
    [SVM]    [해석     [선형   [다항    /      \
    [KNN]    필요?]   회귀]   회귀]  [예]    [아니오]

  ※ 성능이 중요하면 → 블랙박스(앙상블, 신경망, SVM)

  ※ 시계열/텍스트 → RNN/LSTM/트랜스포머
  ※ 이상치가 많으면 → DBSCAN, K-Medoids
  ※ 텍스트 토픽 발견 → LDA (토픽 모델링)

  ※ 변수 많고 공선성 → PCR/PLS 또는 라쏘
  ※ 시계열 + 계절성 → SARIMA 또는 Holt-Winters (삼중 지수평활법)

### 알고리즘별 장단점 실무 비교 총정리표

| 알고리즘 | 장점 | 단점 | 적합한 상황 |
|----------|------|------|-------------|
| **선형회귀** | 해석 쉬움, 빠름 | 비선형 불가, 이상치 민감 | 변수 간 선형 관계가 명확할 때 |
| **로지스틱 회귀** | 확률 해석, 빠름 | 비선형 경계 불가 | 이진분류, 해석이 중요할 때 |
| **의사결정나무** | 해석 최고(화이트박스), 비선형 가능 | 과적합 심함, 불안정 | 해석이 가장 중요할 때 |
| **랜덤포레스트** | 과적합에 강건, 이상치에 강건 | 해석 어려움(블랙박스) | 범용적, 첫 번째로 시도할 모델 |
| **XGBoost/LightGBM** | 최고 수준 성능 | 하이퍼파라미터 많음, 과적합 주의 | 정형 데이터 대회/실무 |
| **SVM** | 고차원에 강함, 커널로 비선형 가능 | 대용량 느림, 해석 어려움 | 중소규모, 고차원 데이터 |
| **KNN** | 구현 간단, 학습 불필요 | 대용량 느림, 차원의 저주 | 소규모, 탐색적 분석 |
| **인공신경망/딥러닝** | 어떤 패턴이든 학습 가능 | 대량 데이터/연산 필요, 블랙박스 | 이미지, 텍스트, 대규모 데이터 |
| **K-Means** | 빠름, 구현 간단 | K 사전 지정, 이상치 민감 | 군집 수를 알 때 |
| **DBSCAN** | K 불필요, 이상치 자동 탐지 | 밀도 차이 큰 데이터에 약함 | 이상치 탐지, 비정형 군집 |
| **나이브 베이즈** | 매우 빠름, 적은 데이터에도 작동 | 독립 가정이 비현실적 | 텍스트 분류(스팸 필터) |
| **다항회귀** | 비선형 관계 모델링, OLS 그대로 사용 | 차수 높으면 과적합 | 포물선 형태의 관계 |
| **PCR/PLS** | 다중공선성 해소, 차원축소 | 해석 어려움, 성분 수 결정 필요 | 변수 >> 관측치인 고차원 데이터 |
| **GAN** | 진짜 같은 데이터 생성 | 학습 불안정, 모드 붕괴 | 이미지 생성, 데이터 증강 |
| **LDA(토픽)** | 숨은 주제 자동 발견, 해석 용이 | 토픽 수 사전 지정 필요 | 문서 분류, 트렌드 파악 |

## 1장: 분석 모형 설계

### 1.1 과대적합과 과소적합

**한 줄 요약**: 모델이 너무 공부를 많이 하면 과대적합, 너무 적게 하면 과소적합이다.

**왜 필요한가**: 모델링의 궁극적 목표는 "처음 보는 데이터도 잘 맞추는 것"(일반화)이다. 과적합/과소적합을 모르면 좋은 모델을 만들 수 없다.

**핵심 설명**:

시험공부에 비유해보자.
- **과대적합(Overfitting)**: 기출문제 답을 통째로 외워서, 같은 문제는 100점이지만 새 문제는 못 푸는 상태. 모델이 훈련 데이터에 지나치게 맞춰져서 복잡해진 것.
- **과소적합(Underfitting)**: 공부를 너무 안 해서 기출도 못 푸는 상태. 모델이 데이터를 충분히 설명하지 못하는 것.
- **일반화(Generalization)**: 기출도 잘 풀고, 새 문제도 적당히 잘 푸는 상태. 우리가 원하는 것.

```
과소적합          적절한 모형          과대적합
  |                  /\                 ~~~~
  |    직선 하나    /  \  적절한 곡선   구불구불 곡선
  |   (너무 단순)  /    \ (일반화됨)    (너무 복잡)
```

⚠️ **시험 포인트**:
- **"과적합"이라고만 나오면 = 과대적합**을 의미한다. "과(過)"가 "많다"는 뜻이므로.
- 과대적합 방지 방법: 가지치기, 규제(Regularization), 드롭아웃, 조기종료, 데이터 증가
- 과소적합 해결: 모델 복잡도 증가, 특성(변수) 추가, 학습 더 진행

**체크리스트**:
- [ ] 과대적합 vs 과소적합 차이를 설명할 수 있는가?
- [ ] "과적합"이 과대적합을 의미함을 알고 있는가?
- [ ] 각각의 해결 방법을 3가지 이상 말할 수 있는가?

### 1.2 데이터 분할

**한 줄 요약**: 수집한 데이터를 훈련용/검증용/평가용으로 나눠서 모델을 만들고 검증하고 최종 평가한다.

**왜 필요한가**: 100개 문제를 전부 공부에만 쓰면, 내가 진짜 실력이 있는지 확인할 방법이 없다. 일부를 자체 모의고사용으로 남겨둬야 한다.

**핵심 설명**:

시험 준비에 비유하면:
1. **훈련(Training) 데이터 ~60%**: 기출문제로 실제 공부하는 부분
2. **검증(Validation) 데이터 ~20%**: 자체 모의고사. 부족한 점을 파악하고 다시 공부하는 반복 과정에 사용
3. **평가(Test) 데이터 ~20%**: 시험 전날 보는 최종 모의고사. 실제 합격 가능성을 판단

```
전체 데이터 (100%)
├── 훈련 데이터 (50~70%) → 모델 학습
├── 검증 데이터 (15~30%) → 하이퍼파라미터 조정, 과적합 점검
└── 평가 데이터 (10~20%) → 최종 성능 측정 (단 1회만 사용)
```

이렇게 분할함으로써:
- 과적합을 방지하고 일반화 성능을 검증할 수 있다

⚠️ **시험 포인트**:
- 검증 데이터는 학습 과정에서 여러 번 사용하지만, 평가 데이터는 최종 1회만 사용
- 데이터 분할 없이 전체 데이터로 학습하면 과대적합 위험이 높다

### 📝 1장 연습문제

**Q1.** 데이터 분할에 대한 설명으로 **틀린** 것은?
1. 훈련 데이터는 모델 학습에 사용한다
2. 검증 데이터는 하이퍼파라미터 튜닝에 사용한다
3. 평가 데이터는 학습 과정에서 여러 번 사용한다
4. 일반적으로 훈련:검증:평가 = 6:2:2로 나눈다

> **정답: 3번**
> 해설: 평가(테스트) 데이터는 최종 성능 확인용으로 **단 1회만** 사용한다. 여러 번 사용하면 평가 데이터에 과적합될 위험이 있다. 여러 번 사용하는 건 검증 데이터.

**Q2.** 과적합을 가장 잘 설명한 것은?
1. 훈련 데이터와 테스트 데이터 모두 성능이 낮다
2. 훈련 데이터 성능은 높지만 테스트 데이터 성능이 낮다
3. 모델이 너무 단순하여 패턴을 못 잡는다
4. 데이터 분할을 하지 않아 발생한다

> **정답: 2번**
> 해설: 1번은 과소적합, 3번도 과소적합의 특징. 4번은 원인 중 하나일 수 있지만 "가장 잘 설명한 것"은 아님. 과적합의 핵심 = 훈련 잘 맞추지만 새 데이터에 일반화 실패.

## 2장: 회귀분석

### 2.1 회귀분석의 기본 개념

**한 줄 요약**: 독립변수(원인)로 종속변수(결과)를 예측하는 분석 기법이다.

**왜 필요한가**: "구독자 수가 늘면 수익이 얼마나 늘어날까?", "집 크기가 커지면 집값이 얼마나 오를까?" 같은 질문에 답하는 가장 기본적인 분석 방법이다.

**핵심 설명**:

유튜브를 처음 시작한다고 해보자. "구독자가 많으면 수익이 높겠지?"라는 의문이 있다. 주변 유튜버들에게 구독자 수와 수익을 물어봐서 데이터를 모았다.

```
수익(y)
  |          *
  |        *   *
  |      *  *
  |    *  *
  |  * *
  |_*____________ 구독자수(x)
```

이 점들 사이에 **가장 잘 맞는 직선**을 하나 찾는 것이 회귀분석이다.

📝 **보충: 산점도 + 회귀선 시각화**
```
수익(y)
  |                      *
  |                  *  /
  |              * * / *      ← 잔차(실제값-예측값)
  |            * / *          ← 이 간격이 작을수록 좋은 모형
  |          / *  *
  |        / *
  |      /* *        ← 점: 실제 데이터
  |    / *           ← 직선: 회귀선 (예측값)
  |  /*
  | /
  +----------------------------→ 구독자수(x)
```
회귀선 위의 점: 잔차 양수(+), 아래의 점: 잔차 음수(-)

- **y = wx + b** (종속변수 = 가중치 x 독립변수 + 절편)
- **x (독립변수)**: 원인이 되는 변수 (구독자 수)
- **y (종속변수)**: 결과가 되는 변수 (수익)
- **w (가중치/회귀계수)**: 기울기. x가 1 증가할 때 y가 얼마나 변하는지
- **b (절편/편향)**: x가 0일 때 y값

### 2.2 최소제곱법 (Least Squares Method)

**한 줄 요약**: 예측값과 실제값의 차이(잔차)가 가장 작아지는 직선을 찾는 수학적 방법이다.

**왜 필요한가**: 직선을 무수히 많이 그릴 수 있는데, 그중에서 "최적의" 직선을 어떻게 고르느냐의 문제다.

**핵심 설명**:

3개의 직선 후보가 있다고 하자. 어떤 직선이 데이터를 가장 잘 대표할까?

각 데이터 점에서 직선까지의 거리(잔차)를 재보면 된다:
- 잔차(Residual) = 실제값 - 예측값
- 위에 있는 점: 잔차가 양수(+)
- 아래에 있는 점: 잔차가 음수(-)
- 그냥 더하면 +와 -가 상쇄되므로 → **제곱해서 더한다**

```
SSE = Σ(실제값 - 예측값)² = 잔차의 제곱합 (Sum of Squared Errors)
```

SSE는 제곱이니까 **2차 함수(포물선)** 형태가 된다. 이 포물선의 최솟값을 찾으면 최적의 직선이다.

수학적으로는 **미분 = 0**인 지점을 찾으면 된다. 이것이 바로 **최소제곱법(최소자승법)**.

> 💡 **직관**: 포물선의 꼭짓점(가장 낮은 점)에서 접선이 수평 = 미분이 0. 그 지점이 SSE가 최소인 최적해다.

⚠️ **시험 포인트**:
- 최소제곱법 = 최소자승법 = SSE를 최소화하는 방법
- 선형회귀에서 회귀계수(가중치)와 절편을 추정하는 핵심 방법

---

### 2.3 결정계수 (R-squared, R²)

**한 줄 요약**: 내 모형이 데이터를 얼마나 잘 설명하는지 0~1 사이 점수로 나타낸 것이다.

**왜 필요한가**: "그래서 이 모형이 얼마나 좋은 건데?"라는 질문에 답하는 지표다.

**핵심 설명**:

세 가지 변동을 이해해야 한다:

| 약자 | 이름 | 의미 | 비유 |
|------|------|------|------|
| **SST** | 총변동 (Total) | 전체 데이터의 흩어진 정도 | 전체 퍼즐 조각 |
| **SSR** | 회귀변동 (Regression) | 모형이 설명하는 변동 | 맞춘 퍼즐 조각 |
| **SSE** | 오차변동 (Error) | 모형이 설명 못하는 변동 | 못 맞춘 퍼즐 조각 |

**핵심 관계**: SST = SSR + SSE (전체 = 설명된 + 설명 안 된)

```
R² = SSR / SST = 1 - (SSE / SST)
```

- R² = 1: 모형이 데이터를 100% 설명 (완벽)
- R² = 0: 모형이 아무것도 설명 못함
- R²가 1에 가까울수록 좋은 모형

⚠️ **시험 포인트**:
- R²는 0~1 사이 값
- SSE가 0이면 R² = 1 (완벽한 설명력)
- **주의**: 일부 교재에서 SSE를 RSS(Residual Sum of Squares)로, SSR을 ESS(Explained Sum of Squares)로 표기한다. 약자의 풀네임을 반드시 확인할 것!

| 표기법1 | 표기법2 | 의미 |
|---------|---------|------|
| SSE | RSS (Residual) | 잔차(오차)의 제곱합 |
| SSR | ESS (Explained) | 설명된 변동의 제곱합 |
| SST | TSS (Total) | 총 변동의 제곱합 |

---

### 2.4 회귀분석의 종류

**한 줄 요약**: 독립변수 개수, 함수 형태, 규제 여부에 따라 여러 종류가 있다.

| 종류 | 설명 | 수식 예시 |
|------|------|-----------|
| **단순회귀** | 독립변수 1개 | y = wx + b |
| **다중회귀** | 독립변수 2개 이상 | y = w1x1 + w2x2 + b |
| **다항회귀** | 2차 이상의 비선형 관계 | y = w1x + w2x² + b |
| **비선형회귀** | 파라미터가 비선형인 관계 | y = a × e^(bx) |
| **주성분회귀(PCR)** | PCA 후 주성분으로 회귀 | 다중공선성 해소 |
| **부분최소제곱(PLS)** | 종속변수와 관련 높은 성분 추출 후 회귀 | PCR보다 예측력↑ |
| **리지회귀** | L2 규제 (과적합 방지) | SSE + λΣw² 최소화 |
| **라쏘회귀** | L1 규제 (변수 선택 효과) | SSE + λΣ\|w\| 최소화 |
| **엘라스틱넷** | L1 + L2 규제 결합 | 리지 + 라쏘 |
| **교호작용 포함 회귀** | 변수 간 시너지 효과 반영 | y = w1x1 + w2x2 + w3(x1*x2) + b |

📝 **보충: 다항 회귀 vs 비선형 회귀**

| 구분 | 다항 회귀 (Polynomial) | 비선형 회귀 (Nonlinear) |
|------|----------------------|----------------------|
| 수식 예시 | y = w₁x + w₂x² + w₃x³ + b | y = a × e^(bx), y = a × x^b |
| 파라미터 | 파라미터(w)에 대해 **선형** | 파라미터에 대해 **비선형** |
| 추정 방법 | 최소제곱법(OLS) 그대로 사용 가능 | 반복적 수치 최적화 필요 (비선형 최소제곱법) |
| 핵심 | x를 x², x³으로 변환하면 독립변수가 늘어난 **다중회귀**와 동일 | 곡선 자체의 형태가 비선형 |

- **다항 회귀의 주의점**: 차수를 높이면 곡선이 복잡해지지만 **과적합** 위험↑. 차수 선택이 핵심.
- **비선형 회귀 활용 예**: 약물 농도-시간 관계, 인구 성장 모형(로지스틱 곡선) 등

> 💡 **왜 다항회귀가 필요한가**: 단순/다중회귀는 직선 관계만 잡을 수 있다. 하지만 "광고비를 처음 늘릴 때는 매출이 크게 오르다가, 어느 수준 이후에는 효과가 줄어드는" 포물선 형태의 관계도 많다. 이때 x² 항을 추가하면 곡선 관계를 모델링할 수 있다. 핵심 트릭은 x² = 새로운 변수로 취급하면 결국 다중회귀와 같은 방법(OLS)으로 풀 수 있다는 점이다.

⚠️ **시험 포인트**: "다항회귀는 독립변수의 거듭제곱을 추가한 것이므로 파라미터에 대해서는 선형이다" → 맞음. 비선형 회귀와 혼동하지 말 것.

📝 **보충: 주성분 회귀(PCR)와 부분최소제곱(PLS)**

독립변수가 많고 다중공선성이 심할 때 사용하는 차원축소 기반 회귀 방법이다.

> 💡 **왜 필요한가**: 다중회귀에서 독립변수가 100개인데 서로 상관관계가 높으면(다중공선성) 모형이 불안정하다. "변수를 줄이되 정보는 보존하자"가 PCR/PLS의 핵심 아이디어다. 비유: 100과목 시험 성적을 "이과 적성", "문과 적성", "체력" 3개로 요약하는 것과 같다.

**주성분 회귀 (PCR, Principal Component Regression)**:
1. 독립변수들에 **PCA(주성분분석)**를 적용하여 주성분(PC) 추출
2. 추출된 주성분을 독립변수로 하여 **회귀분석** 수행
3. 장점: 다중공선성 해소, 차원 축소
4. 단점: 주성분 추출 시 **종속변수(y)를 고려하지 않음** → 예측과 무관한 성분이 포함될 수 있음

**부분최소제곱 (PLS, Partial Least Squares)**:
1. 독립변수와 **종속변수의 공분산을 최대화**하는 방향으로 성분 추출
2. 추출된 성분으로 회귀분석 수행
3. 장점: 종속변수와의 관계를 고려하므로 **PCR보다 예측력이 높은 경우가 많음**
4. 활용: 화학(스펙트럼 데이터), 유전체학 등 변수 >> 관측치인 경우

| 비교 | PCR | PLS |
|------|-----|-----|
| 성분 추출 기준 | X의 분산 최대화 (y 무시) | X와 y의 **공분산** 최대화 |
| 종속변수 반영 | 하지 않음 | 반영함 |
| 예측 성능 | 보통 | 보통~우수 |
| 적합 상황 | 다중공선성 해소 목적 | 예측력 중시 + 다중공선성 해소 |

> 💡 **비유로 차이 이해**: PCR은 "시험 성적과 무관하게 학생들의 특성을 요약"(키, 체중, 시력... → 체격 요인). PLS는 "시험 성적과 관련 있는 특성 위주로 요약"(공부시간, 집중력... → 학습능력 요인). 그래서 PLS가 예측에 더 유리한 경우가 많다.

⚠️ **시험 포인트**: PCR과 PLS의 핵심 차이 = "성분 추출 시 종속변수를 고려하는가?" PCR은 No, PLS는 Yes.

**규제(Regularization)가 뭔가?**

비유: 시험에서 답안지 작성할 때 "한 줄 이내로 답하시오"라는 조건이 규제다. 자유롭게 쓰면 너무 복잡해질 수 있으니, 조건을 걸어서 간결하게 만드는 것.

- **리지(Ridge, L2)**: 가중치를 작게 만들어서 과적합 방지. 변수를 완전히 제거하지는 않음.
- **라쏘(Lasso, L1)**: 불필요한 변수의 가중치를 아예 0으로 만들 수 있음 → 변수 선택 효과
- **엘라스틱넷**: 둘의 장점을 결합

📝 **보충: 규제 회귀 수식 상세 비교**

| 구분 | 비용함수 | 핵심 효과 | 언제 쓰나? |
|------|----------|-----------|------------|
| **리지(L2)** | SSE + λ × Σ(w_i)² | 가중치를 **작게** 만듦 (0에 가깝게, 완전 0은 아님) | 변수가 많고 대부분 유의미할 때 |
| **라쏘(L1)** | SSE + λ × Σ\|w_i\| | 가중치를 **정확히 0**으로 만들 수 있음 → 변수 제거 | 불필요한 변수가 많아 자동 선택이 필요할 때 |
| **엘라스틱넷** | SSE + λ₁ × Σ\|w_i\| + λ₂ × Σ(w_i)² | L1 + L2 결합 | 변수 간 상관관계 높고, 변수 선택도 필요할 때 |

```
가중치 크기
  |
  | ■ ■ ■ ■ ■ ■ ■ ■    ← 규제 없음: 가중치 제각각
  |
  | ▪ ▪ ▪ ▪ ▪ ▪ ▪ ▪    ← 리지(L2): 전체적으로 작아짐, 0은 아님
  |
  | ▪ ▪ 0 ▪ 0 0 ▪ 0    ← 라쏘(L1): 일부가 완전히 0 (변수 제거!)
  +--w1-w2-w3-w4-w5-w6-w7-w8
```

- **λ(람다)**: 규제 강도를 조절하는 하이퍼파라미터. λ가 클수록 규제가 강해져 가중치가 더 작아진다.
- λ = 0이면 규제 없는 일반 회귀와 동일

**교호작용이란?**

예: 고혈압 예측 시 유전 요인은 2배, 비만은 4배 영향. 하지만 유전 + 비만이 동시에 있으면 20배 영향. 이처럼 두 변수가 합쳐져서 시너지를 내는 것이 교호작용이다. 수식에서 x1*x2 항으로 표현한다.

⚠️ **시험 포인트**:
- 리지 = L2, 라쏘 = L1 매칭 자주 출제
- 라쏘는 변수 선택 효과가 있다는 점이 리지와의 핵심 차이
- 교호작용: 2과목 파생변수 개념과 연결

### 2.5 선형회귀의 4가지 가정

**한 줄 요약**: 선형회귀를 올바르게 적용하려면 4가지 조건이 충족돼야 한다.

**암기법**: **선분정독** (선형성, 분산의 등분산성, 정규성, 독립성)

| 가정 | 의미 | 대상 |
|------|------|------|
| **선형성** | 독립변수와 종속변수가 직선 관계 | 변수 간 관계 |
| **등분산성** | 잔차의 분산이 일정 | 잔차 |
| **정규성** | 잔차가 정규분포를 따름 | 잔차 |
| **독립성** | 잔차들이 서로 독립 | 잔차 |

주의: 선형성은 종속변수-독립변수 간 가정이고, 나머지 3개(등분산성, 정규성, 독립성)는 **잔차**에 관한 가정이다.

곡선 형태의 데이터에 직선을 긋고 "회귀분석 했다"고 하면 안 된다. 선형성 가정 위반이다.

⚠️ **시험 포인트**:
- "선분정독" 외우기
- 선형성만 변수 간 가정, 나머지는 잔차 가정 → 이 구분이 시험에 나옴

---

### 2.6 다중공선성 (Multicollinearity)

**한 줄 요약**: 독립변수들끼리 서로 상관관계가 너무 높아서 모형이 불안정해지는 문제이다.

**왜 필요한가**: 시험 문제 무조건 나온다고 강의에서 강조. 회귀분석의 가장 대표적인 함정이다.

**핵심 설명**:

비유: 축구팀에서 감독이 "누가 골을 넣는 데 기여했는지" 분석하고 싶다. 그런데 선수 A와 선수 B가 항상 같이 뛰고 같이 쉰다. 그러면 "A 덕분인지 B 덕분인지" 구분이 안 된다. 이게 다중공선성이다.

- 독립변수들이 종속변수와 상관관계가 높은 건 좋다 (예측에 도움)
- 독립변수들끼리 상관관계가 높으면 나쁘다 (다중공선성 문제)

**진단 방법**:
1. 상관계수 확인: 독립변수 간 상관계수가 높으면 의심
2. **VIF (분산팽창인자, Variance Inflation Factor)**: VIF = 1/(1 - R²_i)
   - R²_i: 독립변수 x_i를 나머지 독립변수들로 회귀했을 때의 결정계수
   - **VIF ≥ 10이면 다중공선성 존재**로 판단
   - VIF = 1이면 다른 변수와 상관관계 전혀 없음
   - 📝 **보충**: 예) x1, x2, x3이 독립변수일 때, x1을 y로 놓고 x2, x3으로 회귀 → R²₁ = 0.9이면 VIF₁ = 1/(1-0.9) = 10 → 다중공선성 존재

**해결 방법**:
1. 상관계수가 높은 독립변수 중 하나를 제거
2. 차원축소 (PCA 등)
3. 규제 적용 (리지, 라쏘)
4. 변수 선택법 사용

⚠️ **시험 포인트**:
- VIF ≥ 10 → 다중공선성 존재 (숫자 반드시 기억)
- 다중공선성이 존재하면 R²가 지나치게 높게 나올 수 있다 (VIF로 확인)
- 해결법 4가지 중 하나를 고르는 문제 자주 출제
- **10회 기출**: "독립변수 간 상관계수를 높이는 것"은 다중공선성을 악화시키는 것이므로 해결책이 아님

---

### 2.7 최적 회귀방정식 탐색

**한 줄 요약**: 어떤 변수를 넣고 뺄지 체계적으로 탐색하는 방법이다.

| 방법 | 동작 방식 | 비유 |
|------|-----------|------|
| **전진선택법** | 변수를 하나씩 추가 | 빈 바구니에 물건 하나씩 넣기 |
| **후진제거법** | 전체에서 변수를 하나씩 제거 | 꽉 찬 바구니에서 하나씩 빼기 |
| **단계별선택법** | 추가와 제거를 번갈아 수행 | 넣었다 뺐다 반복 |

**평가 기준**: AIC, BIC (Mallow's Cp도 있음)
- **AIC, BIC 모두 작을수록 좋다** (벌점 개념)

⚠️ **시험 포인트**:
- 전진/후진/단계별 선택법 차이
- AIC, BIC는 작을수록 좋다

---

### 2.8 회귀모형 구축 절차

1. 독립변수, 종속변수 설정
2. 회귀계수(가중치)와 절편 추정 → **최소제곱법**
3. 개별 회귀계수의 유의성 검정 → **t 검정**
4. 모형 전체의 유의성 검정 → **F 검정**

⚠️ **시험 포인트**:
- 회귀계수 검정 = t검정, 모형 전체 검정 = F검정 (이 매칭 자주 출제)

## 3장: 로지스틱 회귀분석

### 3.1 로지스틱 회귀의 원리

**한 줄 요약**: 회귀분석을 변형해서 "분류" 문제(0 또는 1)를 해결하는 기법이다.

**왜 필요한가**: 회귀분석은 "수치"를 예측하지만(집값, 수익), 현실에서는 "분류" 문제가 더 많다. 합격/불합격, 질병 유/무, 스팸/정상 등.

> **[회귀 → 로지스틱 연결]** 선형회귀의 출력은 -무한~+무한인데, 확률(0~1)이 필요한 분류 문제에는 맞지 않다. 그래서 출력을 0~1로 압축해주는 **시그모이드 함수**를 씌운 것이 로지스틱 회귀다. 즉, 선형회귀를 "분류용으로 업그레이드"한 것이다.

**핵심 설명**:

**단계별로 이해하기**:

1. **오즈(Odds)**: 성공확률 / 실패확률
   - 성공확률이 0.8이면 오즈 = 0.8/0.2 = 4 ("성공이 실패보다 4배 높다")

2. **로짓 변환**: 오즈에 자연로그(ln)를 씌움 → 선형 관계로 변환
   - 자연로그(ln): 밑이 e(약 2.718)인 로그. 큰 수를 작게 만드는 변환
   - ln(오즈) = wx + b (직선 형태가 됨!)
   - 이래서 "회귀"라는 이름이 붙는 것

3. **시그모이드 함수**: 로짓 변환을 역함수로 정리하면 확률(p)로 표현 가능
   ```
   p = 1 / (1 + e^(-(wx+b)))
   ```
   - 출력값이 항상 **0~1 사이** (확률로 해석 가능)
   - 0.5보다 크면 "성공", 작으면 "실패"로 분류

```
확률(p)
  1 |            ___________
    |          /
0.5 |--------/-------------- (기준선)
    |      /
  0 |____/
    +---------------------------> x
```

**구체적 예시**:
- A학생 80점, B학생 70점, C학생 60점, D학생 50점
- y = x - 65 로 변환하면: A→15, B→5, C→-5, D→-15
- 시그모이드에 넣으면: A,B는 0.5 이상(상위권), C,D는 0.5 미만(하위권)

**최대우도법**:
- 선형회귀: SSE를 최소화 → 최소제곱법
- 로지스틱회귀: 확률(우도)을 최대화 → **최대우도법**

⚠️ **시험 포인트**:
- 오즈 = 성공확률/실패확률 (정의 자주 출제)
- 로짓 변환 = 오즈에 자연로그를 씌움
- 시그모이드 함수: 0~1 사이 출력, 분류 문제에 사용
- 로지스틱 회귀는 **최대우도법**으로 추정 (최소제곱법이 아님!)
- **10회 기출**: 오즈를 선형화시키는 것 = 로짓 변환 (자연로그를 씌움)

📝 **보충: 시그모이드 함수 상세 ASCII**
```
확률(p)
  1.0 |                          ●●●●●●●●●●●●
      |                       ●●
      |                     ●●
      |                    ●
  0.5 |------------------●--------------------  ← 판별 기준선
      |                ●
      |              ●●
      |           ●●
  0.0 |●●●●●●●●●●
      +----+----+----+----+----+----+----+----→ wx + b
         -4   -3   -2   -1    0    1    2    3

  특징:
  - 출력값이 항상 0~1 사이 (확률 해석 가능)
  - x=0일 때 출력 = 0.5 (정확히 중간)
  - S자 형태 → 시그모이드(sigmoid = S자 모양)
  - 양 끝으로 갈수록 기울기가 0에 가까워짐 → 기울기 소실 원인
```

## 4장: 의사결정나무 (Decision Tree)

### 4.1 의사결정나무의 기본 개념

**한 줄 요약**: 스무고개처럼 질문을 반복해서 데이터를 분류하거나 예측하는 트리(나무) 구조 모델이다.

**왜 필요한가**: 시험에 정말 자주 나온다. 직관적이고 해석이 쉬워서 실무에서도 많이 쓴다.

> **[로지스틱 → 의사결정나무 연결]** 로지스틱 회귀는 "직선(평면) 경계"로만 분류한다. 하지만 현실 데이터는 복잡하게 섞여있다. 의사결정나무는 질문을 반복해서 "계단 형태의 비선형 경계"를 만든다. 해석도 쉽다. 다만 과적합이 심해서 → 이후 앙상블(랜덤포레스트, 부스팅)로 발전하게 된다.

**핵심 설명**:

스무고개 게임을 생각해보자:
```
          [날개 있니?]
         /            \
       예               아니오
   [날 수 있니?]      [털 있니?]
   /        \          /       \
  예        아니오     예      아니오
 독수리     펭귄      곰      물고기
```

각 질문에서 같은 종류끼리 모이도록 나눈다:
- **노드 내 동질성**이 커지고 (같은 그룹은 비슷해지고)
- **노드 간 이질성**이 커지는 (다른 그룹은 달라지는) 방향으로 분리

**주요 특징**:
- **화이트박스 모델**: 내부 구조가 잘 보여서 해석이 쉽다 (블랙박스의 반대)
- 분류나무, 회귀나무 모두 가능
- **과적합이 잘 일어남**: 계속 분할하면 훈련 데이터에 너무 특화됨

**과적합 방지**:
1. **정지 규칙**: "더 이상 분리하지 마!" → 나무 성장을 미리 멈춤
2. **가지치기(Pruning)**: 불필요한 가지를 잘라냄

⚠️ **시험 포인트**:
- 의사결정나무 = 화이트박스 모델 (해석 용이)
- 과적합 방지 = 가지치기
- **10회 기출**: "데이터양이 많아지면 적합하지 않다" → 틀림. 어떤 모델이든 데이터는 많을수록 좋다
- **10회 기출**: 가지치기 하는 이유 = 과적합 방지

### 4.2 노드 분할 기준

**한 줄 요약**: 어떤 질문으로 나눌지 결정하는 수학적 지표이다.

**분류 모델의 분할 기준**:

| 지표 | 알고리즘 | 특징 |
|------|----------|------|
| **지니 지수** | CART | 불순도 측정. 0에 가까울수록 순수 |
| **엔트로피 지수** | C4.5, ID3 | 정보 이득 기반. 0에 가까울수록 순수 |
| **카이제곱 통계량** | CHAID | 통계적 유의성 기반 |

**회귀 모델의 분할 기준**: 분산 감소량, F-통계량 등

**지니 지수 계산법**:

지니 지수 = 1 - Σ(p_i)²

예: 동전 5개 중 앞면 3개, 뒷면 2개
- p(앞) = 3/5 = 0.6, p(뒤) = 2/5 = 0.4
- 지니 = 1 - (0.6² + 0.4²) = 1 - (0.36 + 0.16) = 1 - 0.52 = 0.48

> 💡 이진분류에서 지니 범위: 0(순수) ~ 0.5(최대불순도, 50:50)

**엔트로피 지수 계산법**:

엔트로피 = -Σ p_i × log₂(p_i)

⚠️ **시험 포인트**:
- **지니 지수와 엔트로피 지수 수식을 외워야 한다** (계산 문제 자주 출제)
- 지니 지수가 계산이 더 쉬워서 시험에 더 자주 나옴
- 지니 지수 = 0이면 완벽하게 순수한 노드
- CART는 지니, C4.5/ID3은 엔트로피 매칭 기억

📝 **보충: 의사결정나무 알고리즘 정밀 비교**

| 알고리즘 | 분할기준 | 분할 방식 | 목적변수 | 특징 |
|----------|----------|-----------|----------|------|
| **ID3** | 엔트로피(정보이득) | 다지분할 | 범주형만 | 가장 초기 알고리즘, 연속형 처리 불가 |
| **C4.5** | 정보이득비(Gain Ratio) | 다지분할 | 범주+연속 | ID3 개선, 결측치 처리 가능 |
| **C5.0** | 정보이득비 | 다지분할 | 범주+연속 | C4.5 개선, 속도/메모리 효율 향상 |
| **CART** | 지니지수 | **이진분할** | 범주+연속 | 항상 2개로만 분할, 가장 많이 사용 |
| **CHAID** | 카이제곱 통계량 | 다지분할 | 범주형 | 통계적 유의성 기반 |

```
[ID3 트리 예시 - 다지분할]              [CART 트리 예시 - 이진분할]
      [날씨?]                              [날씨=맑음?]
    /   |    \                            /            \
  맑음  흐림  비                        예               아니오
  /     |     \                     [습도≤75?]         [바람=강?]
운동X  운동O  운동X                /         \         /        \
                                 예         아니오    예       아니오
                               운동O       운동X    운동X     운동O

※ ID3: 범주 수만큼 가지가 나뉨(다지)
※ CART: 항상 Yes/No 두 갈래(이진)
```

📝 **보충: 차원의 저주 (Curse of Dimensionality)**

변수(차원)가 너무 많아지면 오히려 모델 성능이 떨어지는 현상이다.

비유: 1차원(직선)에서 10개의 점은 빽빽하지만, 100차원 공간에 10개의 점을 놓으면 서로 엄청나게 멀리 떨어진다. 데이터가 희박해져서 패턴을 찾기 어려워진다.

```
1차원: ●●●●●●●●●●  (밀집)
2차원: ●   ●        (좀 흩어짐)
       ●     ●
       ●  ●   ●
100차원: ●            ●           ●    (극도로 희박)
```

해결법: PCA(주성분분석), 변수 선택, 라쏘 규제 등으로 차원 축소

**Q2.** 지니 지수 = 0.48인 노드에 대한 해석으로 옳은 것은?
1. 해당 노드는 완벽하게 순수하다
2. 해당 노드의 불순도가 높다
3. 지니 지수는 0~0.5 범위이므로 최대 불순도이다
4. 추가 분할이 필요 없다

> **정답: 2번**
> 해설: 지니 지수가 0이면 완벽하게 순수(1번 틀림). 이진분류 시 지니 지수 최댓값은 0.5(50:50일 때)이므로 0.48은 최대에 가까운 매우 높은 불순도. 3번은 "범위"는 맞지만 "최대 불순도"라고 단정하면 틀림(정확히 0.5일 때가 최대). 불순도가 높으므로 추가 분할 필요(4번 틀림).

**Q3.** 의사결정나무의 가지치기(Pruning)를 수행하는 가장 주된 이유는?
1. 학습 속도를 높이기 위해
2. 과소적합을 방지하기 위해
3. 과대적합을 방지하기 위해
4. 변수의 중요도를 파악하기 위해

> **정답: 3번**
> 해설: 가지치기의 핵심 목적은 **과대적합 방지**이다. 나무가 너무 깊이 자라면 훈련 데이터에만 특화되므로, 불필요한 가지를 잘라 일반화 능력을 높인다.

**Q4. [계산 문제]** 노드에 데이터 10개가 있고, 클래스 A가 7개, 클래스 B가 3개일 때 지니 지수는?
1. 0.21
2. 0.42
3. 0.49
4. 0.58

> **정답: 2번**
> 해설: 지니 = 1 - (p_A² + p_B²) = 1 - ((7/10)² + (3/10)²) = 1 - (0.49 + 0.09) = 1 - 0.58 = **0.42**

**Q5. [계산 문제]** 같은 노드에서 엔트로피 지수를 구하면? (log₂(0.7) ≈ -0.515, log₂(0.3) ≈ -1.737)
1. 0.61
2. 0.88
3. 1.00
4. 0.42

> **정답: 2번**
> 해설: 엔트로피 = -(0.7 × log₂(0.7) + 0.3 × log₂(0.3)) = -(0.7 × (-0.515) + 0.3 × (-1.737)) = -(−0.361 − 0.521) = **0.88**

**Q6. [상황 문제]** 대출 심사 모형을 만들어야 하는데, 금융감독원에서 "왜 이 고객의 대출을 거절했는지 설명할 수 있어야 한다"고 요구한다. 가장 적합한 모델은?
1. 랜덤포레스트
2. 인공신경망
3. 의사결정나무
4. SVM

> **정답: 3번**
> 해설: 의사결정나무는 **화이트박스 모델**로 "이 변수가 이 값 이상이면 거절"처럼 의사결정 과정을 명확하게 설명할 수 있다. 나머지는 모두 블랙박스 모델이라 설명이 어렵다.

## 5장: 인공신경망 (Artificial Neural Network)

### 5.1 퍼셉트론

**한 줄 요약**: 인간의 뉴런(신경세포)을 모방한 인공신경망의 기본 단위이다.

**왜 필요한가**: 딥러닝의 근간이 되는 개념. 시험에서 신경망 관련 문제가 점점 많아지는 추세.

> **[의사결정나무/SVM → 신경망 연결]** 의사결정나무와 SVM은 사람이 특징(변수)을 잘 설계해줘야 한다. 신경망은 데이터에서 **특징을 스스로 학습**한다. 데이터가 충분하면 사람보다 나은 특징을 찾아낸다. 단, 해석이 어렵고(블랙박스) 데이터/연산량이 많이 필요하다.

**핵심 설명**:

생명과학 시간에 배운 뉴런을 떠올려보자:
- 시냅스로 신호를 받아서 → 종합해서 → 다음 뉴런에 전달

퍼셉트론도 똑같다:
```
입력1 ---(w1)---\
                  [합산 + 활성함수] ---> 출력
입력2 ---(w2)---/
         + 편향(b)
```

출력 = 활성함수(w1×입력1 + w2×입력2 + b)

이 수식을 보면... **다중선형회귀**와 같은 형태다! 즉 선형 문제밖에 못 푼다.

---

### 5.2 다층 퍼셉트론 (MLP)

**한 줄 요약**: 퍼셉트론 여러 개를 층층이 쌓아 복잡한 문제를 풀 수 있게 만든 구조이다.

📝 **보충: 다층 퍼셉트론(MLP) 상세 구조도**
```
  입력층(2)       은닉층1(3)      은닉층2(3)       출력층(2)

   x1 ○─────────○ h1 ─────────○ h4 ─────────○ y1
       ╲╲       ╱│╲           ╱│╲           ╱
        ╲╲     ╱ │ ╲         ╱ │ ╲         ╱
         ╲╲   ╱  │  ╲       ╱  │  ╲       ╱
          ╲╲ ╱   │   ╲     ╱   │   ╲     ╱
   x2 ○────╳────○ h2 ──╳──○ h5 ──╳──○ y2
          ╱╱ ╲   │   ╱     ╲   │   ╱
         ╱╱   ╲  │  ╱       ╲  │  ╱
        ╱╱     ╲ │ ╱         ╲ │ ╱
       ╱╱       ╲│╱           ╲│╱
              ○ h3             ○ h6

  모든 노드 사이에 가중치(w)가 있고, 각 노드에 편향(b)이 있다.
  → 가중치, 편향 = 파라미터 (학습으로 자동 결정)
  → 층 수, 노드 수 = 하이퍼파라미터 (사용자가 설정)
```

- **입력층**: 데이터가 들어오는 곳
- **은닉층(Hidden Layer)**: 입력층과 출력층 사이에 숨어있는 층. 개수는 사용자가 설정(하이퍼파라미터)
- **출력층**: 최종 결과가 나오는 곳

**가중치**: 퍼셉트론 간 연결의 강도. 학습을 통해 자동으로 조정됨 → **파라미터**

은닉층의 수와 노드 수는 사용자가 설정 → **하이퍼파라미터**

| 구분 | 파라미터 | 하이퍼파라미터 |
|------|----------|----------------|
| 설정 주체 | 학습으로 자동 조정 | 사용자가 직접 설정 |
| 예시 | 가중치, 편향 | 은닉층 수, 노드 수, 학습률, K(KNN) |

⚠️ **시험 포인트**:
- **10회 기출**: "인공신경망의 가중치"는 하이퍼파라미터가 아니라 **파라미터**다 (학습으로 자동 조정)
- KNN의 K, 은닉층 수, 학습률 = 하이퍼파라미터
- 은닉층이 많으면 → 복잡해짐 → 과적합 위험 증가
- 은닉층이 적으면 → 단순함 → 과소적합 가능
- 인공신경망 = **블랙박스** 모델 (의사결정나무와 반대)

### 5.3 활성함수

**한 줄 요약**: 선형 연산의 한계를 깨고 비선형 문제를 풀 수 있게 해주는 핵심 함수이다.

**왜 필요한가**: 퍼셉트론은 선형의 조합이니, 아무리 많이 연결해도 결국 선형이다. 컴퓨터의 가장 기초 연산인 XOR 문제조차 못 푼다. 활성함수를 넣어야 비선형이 되어 복잡한 문제를 풀 수 있다.

**은닉층의 활성함수들**:

| 함수 | 출력 범위 | 특징 | 한계 |
|------|-----------|------|------|
| **시그모이드** | 0~1 | 확률 해석 가능 | 기울기 소실 문제 발생 |
| **하이퍼볼릭 탄젠트(tanh)** | -1~1 | 시그모이드보다 범위 넓음 | 기울기 소실 완화했으나 완전 해결 안됨 |
| **ReLU** | 0 또는 자기자신 | 계산 간단, 기울기 소실 해결 | 음수 입력에서 뉴런 죽음(Dead ReLU) |

📝 **보충: 활성함수 그래프 상세 비교**
```
  시그모이드 (0~1)           tanh (-1~1)              ReLU (0~∞)

  1 |      ____              1 |      ____             y |        /
    |     /                    |     /                   |       /
    |    /                     |    /                    |      /
 0.5|---/---                 0 |---/---                  |     /
    |  /                       |  /                      |    /
    | /                        | /                       |   /
  0 |/                      -1 |/                      0 |--/--------
    +--------→ x              +--------→ x               +--------→ x

  수식:                       수식:                     수식:
  σ(x) = 1/(1+e^-x)        tanh(x) = (e^x-e^-x)     f(x) = max(0,x)
                                      /(e^x+e^-x)
  문제: 기울기 소실 심각    문제: 기울기 소실 완화    장점: 기울기 소실 해결
  범위: 0~1 (양수만)        범위: -1~1 (0 중심)      문제: Dead ReLU
```

**ReLU 함수 상세**:
- 입력이 0 이하 → 출력 0
- 입력이 0 초과 → 출력 = 입력 그대로
- **기울기 소실 문제를 해결**한 핵심 활성함수
- 시그모이드보다 계산이 훨씬 간단

**출력층의 활성함수**:

| 문제 유형 | 활성함수 | 설명 |
|-----------|----------|------|
| **이진분류** (강아지 vs 고양이) | **시그모이드** | 0~1 확률 출력 |
| **다중분류** (강아지/고양이/새) | **소프트맥스** | 각 클래스의 확률 출력, 합=1 |
| **회귀** | 없음 (항등함수) | 수치 그대로 출력 |

**소프트맥스 함수**: 출력이 여러 개일 때, 각 출력의 확률 합이 1이 되도록 만들어 준다.
- 예: 강아지 0.5, 고양이 0.2, 송아지 0.2, 말 0.1 → 합 = 1.0

⚠️ **시험 포인트**:
- **10회 기출**: "ReLU 함수는 과적합 방지 목적이다" → 틀림. ReLU는 **비선형 문제 해결 + 기울기 소실 문제 방지** 목적
- **10회 기출**: ReLU는 양의 입력에 대해 선형적으로 반응한다 → 맞음
- **10회 기출**: "은닉층이 많아도 활성함수가 없으면 비선형 표현에 제한된다" → 맞음
- **10회 기출**: CNN에서도 활성함수(ReLU)를 사용한다
- 시그모이드 → 기울기 소실 → tanh → 여전히 문제 → ReLU로 해결 (진화 순서 기억)

### 5.4 손실함수

**한 줄 요약**: 예측값과 실제값의 차이를 측정하는 함수로, 이것을 최소화하는 것이 학습의 목표다.

| 문제 유형 | 손실함수 |
|-----------|----------|
| **회귀** | MSE (Mean Squared Error, 평균제곱오차) |
| **분류** | Cross Entropy (교차 엔트로피) |

손실함수도 아래로 볼록한 형태(2차 함수와 유사)여서, 최솟값을 찾는 것이 목표다. 선형회귀에서 SSE를 최소화했던 것과 같은 원리.

---

### 5.5 순전파와 역전파

**한 줄 요약**: 순전파로 예측하고, 역전파로 가중치를 수정하는 것이 신경망 학습의 핵심이다.

**핵심 설명**:

1. **순전파(Forward Propagation)**: 입력 → 은닉층 → 출력 방향으로 정보 전달. 예측값 산출.
2. 예측값과 실제값의 **오차(손실)** 계산
3. **역전파(Backpropagation)**: 출력 → 은닉층 → 입력 방향으로 오차를 전파. 각 가중치를 갱신.
4. 1~3을 반복하여 손실함수를 줄여나감

```
순전파: 입력 ----→ 은닉층 ----→ 출력 ----→ 손실 계산
                                              |
역전파: 가중치 갱신 ←---- 은닉층 ←---- 출력 ←--┘
```

### 5.6 경사하강법 (Gradient Descent)

**한 줄 요약**: 손실함수의 경사(기울기)를 따라 내려가서 최솟값을 찾는 최적화 방법이다.

**왜 필요한가**: 선형회귀는 미분=0으로 한 번에 답을 구할 수 있었지만, 신경망은 너무 복잡해서 한 번에 답을 못 구한다. 그래서 컴퓨터가 잘하는 "반복"을 활용한다.

비유: 안개 낀 산에서 가장 낮은 골짜기를 찾고 싶다. 눈으로 볼 수 없으니, 발밑의 경사를 느끼면서 계속 내리막 방향으로 걸어간다. 언젠가는 골짜기에 도달한다.

```
손실
  |\
  | \        경사를 따라 내려감
  |  \     ↓
  |   \   ↓
  |    \_↓__  ← 최솟값 (우리가 찾고 싶은 지점)
  |         \
  +------------------→ 가중치
```

**핵심 수식**:

```
w = w - η × ∂L/∂w

w : 현재 가중치 (우리가 조정하려는 값)
η : 학습률 (한 걸음 크기)
∂L/∂w : 손실함수의 기울기 (어느 방향이 내리막인지)
```

> **1차원 수치 예시**: 현재 w=5, 학습률 η=0.1, 기울기 ∂L/∂w=2일 때
> → w = 5 - 0.1 × 2 = **4.8** (가중치가 살짝 줄어든다 = 내리막으로 한 걸음)
> 이걸 수백~수만 번 반복하면 손실이 최소인 지점에 도달

**학습률(Learning Rate)**: 한 걸음의 크기. 너무 크면 최솟값을 건너뛰고, 너무 작으면 도달이 너무 느리다. → 하이퍼파라미터

📝 **보충: 학습률 크기별 차이**
```
[학습률 너무 작음]          [학습률 적당함]            [학습률 너무 큼]
손실                       손실                       손실
  |\                        |\                        |\        /
  | \  ↓ (아주 조금씩)      | \   ↓                   | \   ↗ / ↗ ← 발산!
  |  ↓                      |  \  ↓                   |  ↘/↗
  |   ↓                     |   ↓                     |     ← 최솟값을
  |    ↓                    |    ↘_● 도달!            |        건너뛰고
  |     ↓ (너무 느림)       +--------→ 가중치         |        왔다갔다
  |      ↓...                                         +--------→ 가중치
  +--------→ 가중치

비유: 산에서 내려올 때
- 너무 작은 걸음 → 한참 걸려야 골짜기에 도달 (학습 느림)
- 적당한 걸음   → 효율적으로 골짜기에 도달 (최적)
- 너무 큰 걸음  → 골짜기를 건너뛰어 반대편 산으로 (발산, 학습 실패)
```

### 5.7 기울기 소실 문제

**한 줄 요약**: 깊은 신경망에서 역전파 시 기울기가 점점 작아져서 앞쪽 층의 가중치가 학습되지 않는 문제이다.

경사를 타고 내려가야 하는데, 시그모이드 함수를 쓰면 기울기가 점점 0에 가까워져서 거의 움직이지 못한다.

**해결 순서**:
1. 시그모이드 → 기울기 소실 발생
2. tanh → 완화되었으나 완전 해결 안됨
3. **ReLU → 기울기 소실 문제 극복**

⚠️ **시험 포인트**: ReLU의 가장 중요한 역할 = **기울기 소실 문제 방지** (10회 기출에서도 강조)

---

### 5.8 인공신경망 과적합 방지

**한 줄 요약**: 복잡한 신경망이 훈련 데이터에 너무 특화되는 것을 막는 다양한 기법들이다.

| 방법 | 설명 | 비유 |
|------|------|------|
| **규제 (L1/L2)** | 가중치에 제한을 건다 | 답안지에 글자수 제한 |
| **드롭아웃** | 학습 시 일부 노드를 랜덤하게 꺼놓음 | 반에서 몇 명한테 "손 들지 마" |
| **조기종료** | 과적합되기 전에 학습 중단 | 공부 그만하고 시험 보러 가기 |
| **노드/층 수 줄이기** | 모델 복잡도 자체를 줄임 | 간단한 문제집으로 바꾸기 |
| **데이터 증가** | 학습 데이터를 더 확보 | 문제집을 더 구매 |
| **배치 정규화** | 각 층의 입력을 정규화 | 각 단계에서 기준을 맞춤 |

**드롭아웃 상세 비유**: 교실에서 선생님이 질문하면 항상 같은 학생만 손들고 대답한다. 그러면 그 학생만 학습하고 나머지는 모른다. 그래서 "너는 손 들지 마"하고 랜덤으로 막으면, 다른 학생들도 학습하게 된다.

⚠️ **시험 포인트**:
- **10회 기출**: 과적합 방지 기법 중 "ReLU"는 과적합 방지가 아닌 활성함수(비선형 + 기울기소실 방지)
- 드롭아웃, 조기종료, 규제(L1/L2)는 과적합 방지 맞음

📝 **보충: 배치 정규화(Batch Normalization) 상세**

각 층의 입력 데이터를 정규화(평균 0, 분산 1)하여 학습을 안정화하는 기법이다.

- **왜 필요한가**: 층을 거치면서 데이터의 분포가 계속 바뀜(내부 공변량 이동). 이를 매 층마다 정규화해서 안정시킨다.
- **효과**: 학습 속도 향상, 기울기 소실 완화, 높은 학습률 사용 가능
- **위치**: 보통 활성함수 앞 또는 뒤에 삽입

📝 **보충: 전이학습(Transfer Learning)**

이미 학습된 모델(사전학습 모델)의 가중치를 가져와서, 새로운 문제에 재활용하는 기법이다.

비유: 영어를 잘하는 사람이 프랑스어를 배울 때, 언어 구조에 대한 감각이 있어서 더 빨리 배우는 것과 같다.

- **장점**: 적은 데이터로도 좋은 성능, 학습 시간 대폭 감소
- **대표 사례**: ImageNet으로 학습된 CNN을 의료 영상 분류에 활용
- **방법**: 앞쪽 층(일반적 특징 추출)은 동결(freeze)하고, 뒷쪽 층만 재학습

## 6장: 서포트 벡터 머신 (SVM)

### 6.1 SVM의 기본 개념

**한 줄 요약**: 두 클래스 사이의 간격(마진)이 최대가 되는 경계선(초평면)을 찾는 분류 모델이다.

**왜 필요한가**: 강력한 분류 성능. 특히 커널 함수 덕분에 비선형 문제도 해결 가능.

> **[로지스틱/의사결정나무 → SVM 연결]** 로지스틱 회귀는 "확률 기반"으로 경계를 정하고, 의사결정나무는 "질문 기반"으로 나눈다. SVM은 완전히 다른 접근인 **"마진(간격) 최대화"**로 경계를 정한다. 두 클래스 사이의 여백을 최대한 넓게 만들어서 가장 안전한 경계를 찾는다. 커널 트릭까지 쓰면 비선형도 해결된다. 특히 데이터가 적고 변수가 많은 상황(예: 유전자 데이터)에서 강력하다.

**핵심 설명**:

X 데이터와 O 데이터가 있다. 이 둘을 나누는 선(경계)을 찾고 싶다.

```
  X X       O O O
    X X   O O
   X X X    O O
         |
    ←마진→
```

1번, 2번, 3번 직선 중 어떤 게 최적인가? → **두 클래스 사이의 폭(마진)이 가장 넓은 1번 직선**

| 용어 | 의미 |
|------|------|
| **초평면 (Hyperplane)** | 데이터를 나누는 경계선(2D에서는 직선, 3D에서는 평면) |
| **서포트 벡터** | 초평면에 가장 가까운 데이터 포인트들 |
| **마진 (Margin)** | 서포트 벡터와 초평면 사이의 거리 |

📝 **보충: SVM 초평면/마진/서포트벡터 상세 ASCII**
```
       클래스 A (X)              클래스 B (O)

         X   X                     O   O
           X                         O
      X      X  ← 서포트벡터   O      O  ← 서포트벡터
               |  |         |  |
               |  |←-마진-→|  |
               |  |         |  |
               | [초평면]   |  |
               |  |         |  |
      X   X    sv|         |sv    O   O
                  |         |
                  |         |

  ※ sv = 서포트벡터: 초평면에 가장 가까운 데이터 포인트
  ※ 마진 = 두 서포트벡터 사이의 거리 → 이것을 최대화!
  ※ 초평면은 서포트벡터만으로 결정됨 (나머지 데이터는 무관)
```

⚠️ **시험 포인트**:
- **10회 기출**: "모든 학습 데이터가 서포트 벡터에 영향을 준다" → 틀림. **가장 가까운 데이터(서포트 벡터)만** 초평면 결정에 영향
- **10회 기출**: "커널 트릭을 사용하지 않으면 선형 분류기로 동작한다" → 맞음

### 6.2 커널 함수 (Kernel Trick)

**한 줄 요약**: 직선으로 분류 불가능한 데이터를 고차원으로 변환해서 분류 가능하게 만드는 기법이다.

**왜 필요한가**: SVM이 강력한 이유의 핵심. 시험에서도 커널 함수 관련 문제 자주 출제.

비유: 탁자 위에 빨간 구슬과 파란 구슬이 섞여있는데 직선 하나로 나눌 수 없다. 하지만 탁자를 세게 치면 빨간 구슬은 높이 튀고 파란 구슬은 낮게 튄다. 그러면 공중에서 수평면 하나로 나눌 수 있다!

```
2D: 직선으로 분류 불가        고차원으로 변환 후: 평면으로 분류 가능
    O X O X O                      O   O   O  (위)
    X O X O X                  ----평면----
                                 X   X   X  (아래)
```

저차원 → 고차원으로 매핑하여 초평면을 찾을 수 있게 만드는 것이 커널 함수의 역할.

📝 **보충: 커널 함수의 종류와 단계별 작동 원리**

**주요 커널 함수**:

| 커널 | 특징 | 적합한 상황 |
|------|------|-------------|
| **선형 커널** | 변환 없음 (직선 분류) | 데이터가 선형 분리 가능할 때 |
| **다항식 커널** | d차 다항식으로 변환 | 중간 복잡도의 비선형 |
| **RBF(가우시안) 커널** | 무한 차원으로 매핑 | **가장 많이 사용**, 범용적 |
| **시그모이드 커널** | 신경망과 유사 | 특수한 경우 |

**RBF 커널의 작동을 단계별로 이해하기**:

```
[Step 1] 1차원 데이터: 직선 하나로 분류 불가
   O O O X X X O O O
         (X가 가운데 섞여있음)

[Step 2] RBF 커널이 각 점에서 "높이"를 계산
   → 특정 중심점으로부터의 거리에 따라 높이가 결정됨
   → 가까우면 높고, 멀면 낮음 (가우시안 함수 형태)

[Step 3] 2차원으로 변환 → 평면으로 분류 가능!
   높이 |    X X X
        |   / ̄ ̄ ̄ \  ← 분류 경계(초평면)
        |  O O O   O O O
        +--1--2--3--4--5--6--→ 원래 축

※ 실제로는 고차원 계산을 직접 하지 않고,
   커널 함수라는 "꼼수(트릭)"로 저차원에서 계산함
   → 이것이 "커널 트릭"이라 불리는 이유!
```

**하이퍼파라미터 gamma (γ)**: RBF 커널에서 "영향 범위"를 결정
- γ 큼 → 좁은 범위만 영향 → 복잡한 경계 → **과적합 위험**
- γ 작음 → 넓은 범위 영향 → 단순한 경계 → **과소적합 위험**

### 6.3 하드 마진 vs 소프트 마진

| 구분 | 하드 마진 | 소프트 마진 |
|------|-----------|-------------|
| 오류 허용 | 오류를 전혀 허용하지 않음 | 어느 정도 오류 허용 |
| 과적합 | 과적합 위험 높음 | 과적합 방지 효과 |
| 사용 빈도 | 드물다 | **훨씬 많이 사용** |
| 오류 허용 정도 | - | 하이퍼파라미터(C)로 설정 |

⚠️ **시험 포인트**:
- **10회 기출**: "소프트 마진은 오차를 허용한다" → 맞음
- 하드 마진 = 오류 불허, 소프트 마진 = 오류 허용 구분 확실히

## 7장: 연관분석

### 7.1 연관분석의 개념

**한 줄 요약**: "맥주를 사는 사람은 치킨도 산다" 같은 항목 간 패턴을 찾는 분석이다.

**왜 필요한가**: 마트에서 상품 배치, 추천 시스템 등 실무에서 많이 활용. 시험에서 계산 문제로 매회 출제.

**핵심 설명**:

장바구니 분석이라고도 한다. 마트 거래 내역에서 "A를 사면 B도 산다"는 규칙을 발견하는 것.

**특징**:
- 결과가 단순하고 분명 (IF-THEN 구조)
- **비목적성**: 특별한 목적 없이도 패턴 발견 가능
- 품목 수가 증가하면 **계산량이 기하급수적으로 증가** (단점)
- 시간 개념을 추가하면 → **순차 패턴 분석**

---

### 7.2 연관분석의 3대 지표: 지지도, 신뢰도, 향상도

**암기법**: **지신향** (지지도, 신뢰도, 향상도)

> ⚠️ A→B의 신뢰도와 B→A의 신뢰도는 다르다! 시험에서 방향 바꿔서 함정 출제

| 지표 | 수식 | 의미 | 비유 |
|------|------|------|------|
| **지지도** | P(A∩B) | A와 B가 동시에 거래된 비율 | 두 상품이 함께 팔리는 빈도 |
| **신뢰도** | P(A∩B) / P(A) | A를 살 때 B도 살 확률 | 조건부 확률 |
| **향상도** | P(A∩B) / (P(A)×P(B)) | A와 B의 상관성 | 독립일 때와 비교한 상관도 |

**향상도 해석**:
- 향상도 > 1: 양의 상관관계 (같이 사는 경향)
- 향상도 = 1: 상관 없음 (독립)
- 향상도 < 1: 음의 상관관계 (하나 사면 다른 건 안 사는 경향)

### 7.3 연관분석 계산 예제

**이 유형은 시험에 거의 매회 출제된다!**

| 거래 | 품목 | 거래수 |
|------|------|--------|
| 1 | 맥주, 치킨 | 20 |
| 2 | 맥주, 햄버거 | 30 |
| 3 | 치킨, 햄버거 | 40 |
| 4 | 맥주 | 10 |
| 5 | 치킨, 햄버거, 맥주 | 40 |
| 6 | 치킨 | 30 |
| 7 | 맥주, 치킨 | 20 |
| 8 | 햄버거 | 10 |
| **합계** | | **200** |

**맥주를 구매할 때 치킨을 구매하는 경우:**

1. P(맥주) = (20+30+10+40+20)/200 = 120/200 = **0.6** (거래1,2,4,5,7)
2. P(치킨) = (20+40+40+30+20)/200 = 150/200 = **0.75** (거래1,3,5,6,7)
3. P(맥주∩치킨) = (20+40+20)/200 = 80/200 = **0.4** (거래1,5,7에서 동시 거래)
4. **신뢰도** = P(맥주∩치킨)/P(맥주) = 0.4/0.6 = **0.67** → "맥주를 사면 67% 확률로 치킨도 산다"
5. **향상도** = P(맥주∩치킨)/(P(맥주)×P(치킨)) = 0.4/(0.6×0.75) = **0.89** → 음의 상관관계 (독립일 때보다 약간 낮음)

⚠️ **시험 포인트**: 이런 표가 주어지면 차근차근 수식에 대입하면 된다. 시험 시간은 충분하니 우도표를 그려서 풀기를 추천.

📝 **보충: 연관분석 계산 풀이 흐름 정리**
```
[Step 1] 각 품목별 거래 건수 합산
   P(맥주) = (맥주 포함 거래 건수) / 전체 거래 건수
   P(치킨) = (치킨 포함 거래 건수) / 전체 거래 건수

[Step 2] 동시 거래 건수
   P(맥주∩치킨) = (둘 다 포함된 거래 건수) / 전체 거래 건수

[Step 3] 지표 계산
   지지도   = P(맥주∩치킨)                        ← "함께 팔리는 빈도"
   신뢰도   = P(맥주∩치킨) / P(맥주)              ← "맥주 사면 치킨도 살 확률"
   향상도   = P(맥주∩치킨) / (P(맥주) × P(치킨))  ← "독립 대비 상관도"

[Step 4] 향상도 해석
   > 1 : 양의 상관 (같이 사는 경향)
   = 1 : 무관 (독립)
   < 1 : 음의 상관 (하나 사면 다른 건 안 사는 경향)
```

### 📝 7장 연습문제

**Q1.** 전체 1000건의 거래에서 빵 400건, 우유 300건, 빵∩우유 150건일 때 향상도는?
1. 0.5
2. 1.0
3. 1.25
4. 1.5

> **정답: 3번**
> 해설: 향상도 = P(빵∩우유) / (P(빵)×P(우유)) = (150/1000) / ((400/1000)×(300/1000)) = 0.15 / 0.12 = **1.25**. 1보다 크므로 양의 상관관계.

**Q2.** 연관분석에 대한 설명으로 **틀린** 것은?
1. 비목적성 분석에 해당한다
2. 향상도가 1이면 두 품목은 독립이다
3. 품목 수가 증가하면 계산량이 선형으로 증가한다
4. 시간 개념을 추가하면 순차 패턴 분석이 된다

> **정답: 3번**
> 해설: 품목 수가 증가하면 계산량은 **기하급수적**으로 증가한다(선형이 아님). 이것이 Apriori 알고리즘이 최소 지지도를 설정해 빈발항목만 추출하는 이유다.

**Q3. [계산 문제]** 전체 500건의 거래에서 라면 200건, 김치 250건, 라면∩김치 100건이다. "라면을 사면 김치도 산다"의 신뢰도는?
1. 0.20
2. 0.40
3. 0.50
4. 0.80

> **정답: 3번**
> 해설: 신뢰도 = P(라면∩김치) / P(라면) = (100/500) / (200/500) = 0.2 / 0.4 = **0.50** → "라면을 사면 50% 확률로 김치도 산다"

**Q4. [계산 문제]** 위 문제에서 향상도를 구하면?
1. 0.50
2. 1.00
3. 1.25
4. 2.00

> **정답: 2번**
> 해설: 향상도 = P(라면∩김치) / (P(라면) × P(김치)) = 0.2 / (0.4 × 0.5) = 0.2 / 0.2 = **1.00** → 향상도 = 1이므로 두 품목은 **독립**(상관 없음)이다.

**Q5. [해석 문제]** 어떤 연관규칙의 향상도가 0.7이다. 이에 대한 해석으로 옳은 것은?
1. A를 사면 B도 살 확률이 70%이다
2. A와 B는 양의 상관관계이다
3. A를 사면 B를 오히려 덜 사는 경향이 있다
4. 전체 거래의 70%에서 A와 B가 함께 거래된다

> **정답: 3번**
> 해설: 향상도 < 1이면 **음의 상관관계**이다. 독립일 때보다 함께 구매하는 빈도가 낮다는 의미. 1번은 신뢰도, 4번은 지지도에 대한 설명이다.

### 7.4 Apriori 알고리즘과 FP-Growth

| 알고리즘 | 방식 | 특징 |
|----------|------|------|
| **Apriori** | 최소 지지도를 만족하는 빈발항목을 반복적으로 탐색 | DB를 반복 탐색해야 해서 느림 |
| **FP-Growth** | 트리 기반으로 한 번에 처리 | Apriori보다 연산 효율 향상 |

**Apriori 핵심 아이디어**: 거래가 거의 안 되는 품목(두리안 같은 것)은 굳이 연관분석 할 필요 없다. 최소 지지도를 설정해서 빈발항목만 추출한 뒤 연관규칙을 도출한다.

⚠️ **시험 포인트**: Apriori의 개념, 절차가 출제됨. ADSP에서는 계산까지 출제된 적 있으므로 빅분기에서도 출제 가능성 있음.

📝 **보충: FP-Growth 알고리즘 상세**

Apriori의 단점(DB를 반복 스캔해야 하는 비효율)을 개선한 알고리즘이다.

**핵심 원리**:
1. **1차 스캔**: 전체 DB를 한 번 읽어서 각 항목의 빈도(지지도) 계산
2. **빈발항목 정렬**: 최소 지지도를 넘는 항목만 남기고 빈도 내림차순 정렬
3. **FP-Tree 구축**: 2차 스캔하면서 각 거래를 정렬된 순서대로 트리에 삽입
   - 같은 경로가 있으면 해당 노드의 카운트만 증가 (메모리 절약)
   - 헤더 테이블로 같은 항목의 노드를 연결 (링크드 리스트)
4. **조건부 패턴 베이스 생성**: 각 항목에서 루트까지의 경로를 추출
5. **조건부 FP-Tree 구축 → 빈발 패턴 추출**: 재귀적으로 빈발항목집합 도출

```
FP-Tree 구축 예시 (최소 지지도=2):

거래 데이터:  T1={A,B,C}, T2={A,B}, T3={A,C}, T4={B,C}, T5={A,B,C}
빈도: A=4, B=4, C=4 → 빈도순: A,B,C (동일하면 알파벳순)

             [루트]
            /      \
          A:4      B:1     ← T4에서 A 없이 B부터 시작
         /    \       \
       B:3    C:1     C:1   ← A→B(T1,T2,T5), A→C(T3), B→C(T4)
       /
     C:2                    ← A→B→C(T1,T5)

※ 같은 경로면 카운트만 증가 → 메모리 절약
※ Apriori처럼 후보 생성/DB 재스캔 불필요!
```

**Apriori vs FP-Growth 비교**:

| 비교 항목 | Apriori | FP-Growth |
|-----------|---------|-----------|
| DB 스캔 횟수 | 후보 생성마다 반복 스캔 | **2회만** 스캔 |
| 후보 생성 | 후보 항목집합을 생성 후 검증 | 후보 생성 **없음** (트리에서 직접 추출) |
| 메모리 | 후보 집합이 메모리 차지 | FP-Tree가 메모리 차지 |
| 속도 | 항목 많으면 매우 느림 | 대규모 데이터에서 **훨씬 빠름** |
| 적합 상황 | 소규모 데이터, 이해 용이 | 대규모 데이터, 실무 |

⚠️ **시험 포인트**: "FP-Growth는 후보 항목집합을 생성하지 않는다" → 맞음. "DB를 2회만 스캔한다" → 맞음. Apriori와의 차이를 묻는 문제 주의.

## 8장: 군집분석

### 8.1 군집분석의 개념

**한 줄 요약**: 정답 없이 데이터를 거리나 유사성 기준으로 자동 그룹화하는 비지도 학습이다.

**왜 필요한가**: 고객 세분화, 이상 탐지 등 다양한 곳에서 활용. 시험에서 K-means, DBSCAN, 덴드로그램 관련 문제 매회 출제.

> **지도학습 vs 비지도학습 구분**: 지금까지 배운 회귀/분류 알고리즘은 모두 **정답(레이블)**이 있는 **지도학습**이었다. 군집분석은 정답 없이 "비슷한 것끼리 묶어줘"라고 하는 **비지도학습**이다. 고객을 VIP/일반/이탈위험으로 나누고 싶은데 미리 정해진 기준이 없을 때 사용한다.

📝 **보충: 엘보 메소드(Elbow Method) 시각화**

K-Means에서 최적의 K를 결정하는 대표적 방법이다.

```
SSE(군집 내 오차)
  |
  |\ 
  | \
  |  \
  |   \___        ← 여기가 "팔꿈치(Elbow)"!
  |       \___        K를 더 늘려도 SSE가 크게 줄지 않는 지점
  |           \___\___
  +--1--2--3--4--5--6--7--→ K (군집 수)
         ↑
     최적 K = 3

해석: K=1→2→3으로 갈 때 SSE가 급격히 줄다가,
      K=3 이후로는 완만해짐 → K=3이 최적
```

### 8.2 거리 측정 방법

**연속형 변수의 거리**:

| 거리 | 특징 |
|------|------|
| **유클리디안 거리** | 직선 거리 (피타고라스). 민코프스키 p=2 |
| **맨해튼 거리** | 격자 거리 (택시 거리). 민코프스키 p=1 |
| **민코프스키 거리** | 유클리디안과 맨해튼을 일반화한 거리 |
| **마할라노비스 거리** | **상관관계를 고려**한 거리 (이 특징 기억!) |

민코프스키 거리에서:
- p=1 → 맨해튼 거리
- p=2 → 유클리디안 거리

**범주형 변수의 유사도** (거리 계산이 불가하므로 유사도 사용):

| 유사도 | 측정 방식 |
|--------|-----------|
| **자카드 유사도** | 겹치는 정도 (교집합/합집합) |
| **코사인 유사도** | 벡터 간 각도 |

📝 **보충**: 코사인 유사도는 범주형뿐 아니라 텍스트/벡터 데이터(TF-IDF 등)에서도 핵심적으로 사용됨

⚠️ **시험 포인트**:
- 마할라노비스 거리 = 상관관계 고려
- 범주형은 거리 계산 불가 → 유사도 사용
- 민코프스키 p=1 맨해튼, p=2 유클리디안

### 8.3 계층적 군집분석

**한 줄 요약**: 데이터를 가까운 것끼리 차례로 묶어 올라가면서(또는 내려가면서) 계층 구조를 만드는 방법이다.

**핵심 설명**:

```
데이터 분포: A(1) B(2)     C(10) D(12)     E(20) F(22)

단계1: A-B 묶음 (거리 1로 가장 가까움)
단계2: C-D 묶음, E-F 묶음
단계3: {A,B}-{C,D} 묶음
단계4: 전부 묶음
```

이 과정을 그림으로 표현하면 **덴드로그램(dendrogram)** :

```
높이
25 |          ┌──────────────┐
   |          |              |
15 |    ┌─────┤        ┌─────┤
   |    |     |        |     |
5  |  ┌─┤   ┌─┤      ┌─┤   ┌─┤
   |  A  B   C  D     E  F
```

**덴드로그램 해석** (시험 문제로 자주 나옴):
- 높이 15에서 자르면 → {A,B}, {C,D}, {E,F} = **3개 군집**
- 높이 25에서 자르면 → {A,B,C,D}, {E,F} = **2개 군집**

**군집 간 거리 측정법**:

| 방법 | 기준 |
|------|------|
| **최단 연결법** | 두 군집에서 가장 가까운 데이터 간 거리 |
| **최장 연결법** | 두 군집에서 가장 먼 데이터 간 거리 |
| **평균 연결법** | 모든 데이터 쌍의 평균 거리 |
| **중심 연결법** | 군집 중심(평균) 간 거리 |
| **와드 연결법** | 편차 제곱합이 최소가 되도록 |

⚠️ **시험 포인트**:
- **10회 기출**: 덴드로그램에서 특정 높이에서 자를 때 군집 개수 → 직접 그래프 보고 세면 됨
- 5가지 연결법 이름 기억

### 8.4 K-평균 군집화 (K-Means)

**한 줄 요약**: K개의 군집으로 나누기 위해, 중심점을 반복 조정하면서 데이터를 가장 가까운 중심에 할당하는 방법이다.

**비유**: 운동장에 학생 100명이 흩어져 있다. 선생님이 **깃발 3개**(K=3)를 아무 데나 꽂는다. "가장 가까운 깃발로 모여!" → 모인 학생들의 **한가운데로 깃발 이동** → 다시 "가장 가까운 깃발로!" → 반복. 깃발이 더 이상 안 움직이면 끝. 이게 K-Means다.

**핵심 알고리즘** (반드시 순서대로 기억):
1. 군집 개수 K를 **사전에 설정**
2. K개의 **초기 중심점을 임의 설정**
3. 각 데이터를 **가장 가까운 중심점에 할당**
4. 할당된 데이터의 **평균으로 중심점 재설정**
5. 3~4를 **중심점이 변하지 않을 때까지 반복**

```
초기 상태:          1회 반복 후:          2회 반복 후:
  * * *  ●₁        * * * ●₁             * * *
  * * *             * * *               ●₁ * * *
                    
  ○ ○ ○  ●₂          ○ ○ ○               ○ ○ ○
  ○ ○ ○               ○ ●₂ ○             ○ ○ ●₂ ○
```
(●: 중심점, 화살표 방향으로 중심점이 이동)

**특징**:
- **거리 기반** 군집화
- 안정된 군집은 보장하나 **최적은 보장 어려움**
- **이상치에 민감** (평균을 사용하므로)
- **초기 중심점에 따라 결과 달라질 수 있음**
- K를 사전에 지정해야 함 → **엘보 메소드**로 최적 K 결정

**K-Means의 변형**:

| 변형 | 차이점 |
|------|--------|
| **K-Medoids** | 중심점 대신 실제 데이터 중 대표값 사용 → 이상치에 더 강건 |
| **K-Modes** | 범주형 데이터용. 평균 대신 최빈값 사용 |

⚠️ **시험 포인트**:
- K-Means는 K를 사전에 지정해야 함 (DBSCAN과 차이)
- 이상치에 민감함 (평균 기반이라)
- 최적 K 결정 → 엘보 메소드
- 알고리즘 5단계 순서 기억

📝 **보충: K-Means 반복 과정 상세 ASCII (K=2)**
```
[Step 1] 초기 중심점 임의 배치       [Step 2] 가까운 중심에 할당
  6|  a       b    ●₂               6|  a       b    ●₂
  5|     c                           5|     c         ↑ (b에 가까움)
  4|                                 4|         ↑     |
  3|     ●₁     d                    3|     ●₁  ↑  d
  2|  e                              2|  e  ↑
  1|     f                           1|     f
   +--1--2--3--4--5--6               +--1--2--3--4--5--6
   ●₁(2,3) ●₂(5,6)                  그룹1:{a,c,e,f} 그룹2:{b,d}

[Step 3] 평균으로 중심점 재계산       [Step 4] 다시 할당 → 반복
  6|  a       b                      변화 없으면 종료!
  5|     c                           
  4|        ●₁'                      최종 군집:
  3|            d                      군집1 = {a,c,e,f}  ●₁'
  2|  e            ●₂'               군집2 = {b,d}       ●₂'
  1|     f
   +--1--2--3--4--5--6
   ●₁' = {a,c,e,f}의 평균, ●₂' = {b,d}의 평균
```

### 8.5 DBSCAN

**한 줄 요약**: 데이터가 밀집된 정도(밀도)를 기준으로 군집을 형성하고, 밀도가 낮은 곳의 데이터는 이상치로 처리하는 방법이다.

**왜 필요한가**: K-Means의 단점(K 사전 지정, 이상치 민감)을 극복.

**핵심 설명**:

비유: 사람들이 모여있는 곳을 위에서 드론으로 찍었다. 사람들이 빽빽하게 모인 곳 = 군집, 혼자 떨어져 있는 사람 = 이상치.

밀도의 정의: "내 주변 특정 거리(ε) 안에 데이터가 최소 몇 개(MinPts) 이상 있으면 밀집"

| 파라미터 | 의미 |
|----------|------|
| **ε (epsilon)** | 이웃 반경 (특정 거리) |
| **MinPts** | 최소 데이터 포인트 수 |

둘 다 **하이퍼파라미터** (사용자가 설정)

📝 **보충: DBSCAN 핵심점/경계점/잡음점 ASCII (ε=1, MinPts=3)**
```
    ● ●          ← 핵심점(Core): 반경 ε 안에 MinPts(3)개 이상
   ● ● ●             이웃이 있는 데이터
    ● ●
       ○          ← 경계점(Border): 핵심점의 ε 안에 있지만,
                       자기 자신은 MinPts를 충족 못함

                  ★  ← 잡음점(Noise): 어떤 핵심점의 ε 안에도 속하지 않음
                       → 이상치로 처리!

  상세 그림:
  ┌─────────────────────────────────────┐
  │   (ε 반경)                          │
  │  ○─┐                               │
  │ ●──●──●  ← 핵심점 클러스터         │
  │  ●──●                              │
  │     │○  ← 경계점                    │
  │                                     │
  │                    ★ ← 잡음점       │
  └─────────────────────────────────────┘
```

**K-Means vs DBSCAN 비교** (시험 단골):

| 항목 | K-Means | DBSCAN |
|------|---------|--------|
| 기반 | 거리 | **밀도** |
| 군집 수 지정 | **필요** (K) | **불필요** (자동) |
| 이상치 처리 | 민감 (이상치에 영향받음) | **강건** (이상치를 노이즈로 분리) |
| 군집 형태 | 구형(원형)에 적합 | 비정형 형태도 가능 |
| 하이퍼파라미터 | K | ε, MinPts |

⚠️ **시험 포인트**:
- DBSCAN = 밀도 기반, 군집 수 지정 불필요, 이상치에 강건
- K-Means = 거리 기반, K 사전 지정 필요, 이상치에 민감
- 이 비교표는 거의 매회 출제

### 8.6 기타 군집화 방법

| 방법 | 핵심 특징 |
|------|-----------|
| **퍼지 군집화** | 확률 기반. 한 데이터가 **여러 군집에 속할 수 있음** (K-Means/DBSCAN은 한 곳만) |
| **EM 알고리즘** | 기대값(E) 계산 → 최대화(M) 반복. 우도를 최대화 |
| **자기조직화 지도(SOM)** | 신경망 + 차원축소 + 군집화. 순전파만 사용, 노드 간 경쟁 학습. **격자(Grid) 형태의 경쟁학습** |

📝 **보충**: SOM은 역전파를 쓰지 않고 순전파만 사용한다는 점이 기존 인공신경망과의 핵심 차이다.

📝 **보충: GMM (가우시안 혼합 모델, Gaussian Mixture Model)**

데이터가 여러 개의 정규분포(가우시안)가 혼합된 것이라고 가정하고, 각 분포의 파라미터(평균, 분산, 혼합비율)를 추정하여 군집화하는 방법이다.

- K-Means와 유사하지만, **확률 기반**이라 한 데이터가 여러 군집에 속할 확률을 계산
- **EM 알고리즘**으로 학습 (E단계: 기대값 계산, M단계: 파라미터 갱신)
- 퍼지 군집화의 일종

| 비교 | K-Means | GMM |
|------|---------|-----|
| 소속 | 하나의 군집에만 | 여러 군집에 확률적으로 |
| 군집 형태 | 구형(원형) | 타원형도 가능 |
| 기반 | 거리 | 확률 분포 |

## 9장: 범주형 자료 분석

### 9.1 분할표 (교차표)

**한 줄 요약**: 범주형 변수 두 개를 교차시켜 표로 만들어 관계를 파악하는 기본 방법이다.

**예시**: 알코올 중독(있음/없음) × 심장 질환(있음/없음)

|  | 심장질환 O | 심장질환 X |
|--|-----------|-----------|
| 알코올 O | 0.7 | 0.3 |
| 알코올 X | 0.2 | 0.8 |

**상대 위험도** = 0.7/0.2 = 3.5 → 알코올 중독인 사람의 심장질환이 3.5배 높다

**오즈비**: 각 행의 오즈(성공/실패)의 비율
- 알코올 O의 오즈 = 0.7/0.3
- 알코올 X의 오즈 = 0.2/0.8
- 오즈비 = (0.7/0.3) / (0.2/0.8) = 9.33

### 9.2 카이제곱 검정

**한 줄 요약**: 범주형 자료가 특정 조건을 만족하는지 통계적으로 검정하는 방법이다.

| 검정 유형 | 목적 |
|-----------|------|
| **적합도 검정** | 특정 분포에 적합한지 |

| **동질성 검정** | 두 집단이 동일한 분포인지 |

## 10장: KNN (K-최근접 이웃)

### 10.1 KNN의 원리

**한 줄 요약**: 새 데이터가 들어오면 가장 가까운 K개의 이웃을 보고 다수결로 분류하는 방법이다.

**핵심 설명**:

비유: 새로 이사 온 동네에서 "여기가 부촌인지 아닌지" 알고 싶다. 주변 집 6채를 보니 4채가 고급 주택이고 2채가 보통이다. → "여기는 부촌이다" (다수결)

```
    X   X
  X   ?   O    ← ?는 새 데이터
    X   O
      O
```
K=6일 때: 가장 가까운 6개 중 X가 4개, O가 2개 → **?는 X로 분류**

📝 **보충: K값에 따른 분류 결과 차이**
```
[K=3일 때]                          [K=5일 때]
       O                                  O
    X   X                              X   X
  X  (?)  O   ← 가장 가까운 3개:     X  (?)  O   ← 가장 가까운 5개:
    X   O        X:2, O:1                X   O        X:3, O:2
      O          → X로 분류!              O          → X로 분류!

[K=7일 때]                          주의: K값을 바꾸면 결과가 달라질 수 있다!
       O                            
    X   X                           K가 작으면 → 복잡한 경계 → 과적합 위험
  X  (?)  O   ← 가장 가까운 7개:    K가 크면  → 단순한 경계 → 과소적합 위험
    X   O        X:3, O:4           
      O          → O로 분류!        ※ K는 보통 홀수로 설정 (동점 방지)
       O
```

**특징**:
- K값에 따라 결과가 달라짐 (K는 하이퍼파라미터)
- **별도의 훈련 과정이 없다** → **게으른 학습(Lazy Learning)** 이라고 부름
- 그때그때 거리만 계산하면 됨
- 데이터가 많아지면 계산량 증가

⚠️ **시험 포인트**:
- KNN의 K = 하이퍼파라미터
- 게으른 학습(Lazy Learning) = 사전 훈련 없이 예측 시점에 계산

## 11장: 다변량 분석

### 11.1 개요

**한 줄 요약**: 여러 변수(특징)를 가진 데이터를 종합적으로 분석하는 방법들의 모음이다.

| 분석 방법 | 핵심 |
|-----------|------|
| **분산분석 (ANOVA)** | 여러 집단의 **평균** 비교. y 1개, x 여러 개 |
| **다변량 분산분석 (MANOVA)** | y도 여러 개, x도 여러 개 |
| **요인분석** | 차원축소. 많은 변수를 소수의 요인으로 |
| **정준상관분석** | 두 변수 집합 간의 선형결합 관계 탐색 |

⚠️ **시험 포인트**:
- **10회 기출**: 다중분산분석을 적용하기 적절한 사례 → **종속변수가 여러 개**인 경우
- 분산분석(y 1개) vs 다변량 분산분석(y 여러 개) 차이 기억

### 11.2 주성분분석 (PCA)

📝 **보충** (2과목 내용이지만 3과목에서도 출제)

**한 줄 요약**: 데이터의 분산이 가장 큰 방향을 찾아 차원을 축소하는 대표적인 방법이다.

⚠️ **시험 포인트**:
- **10회 기출**: 분산이 큰 축부터 선택 (분산 클수록 정보 손실 적음)
- 축끼리는 **직교**(서로 독립) → 주성분끼리 정보 공유하지 않음
- 변수 간 상관관계를 고려해서 축소

## 12장: 시계열 분석

### 12.1 시계열 분석의 기본 개념

**한 줄 요약**: 시간 흐름에 따라 관찰된 데이터의 패턴을 파악하여 미래를 예측하는 분석이다.

**왜 필요한가**: 주가, 기온, 매출 등 시간에 따른 데이터는 어디에나 있다. 시험에 무조건 1문제 이상 나온다.

**예시**: 주가 데이터, 기온 데이터, 월별 매출 등

---

### 12.2 정상성 (Stationarity)

**한 줄 요약**: 시계열 분석을 하려면 데이터의 평균과 분산이 시점에 따라 일정하고, **자기공분산이 시차(lag)에만 의존**해야 한다 (시점 자체에 의존하면 안 됨).

비유: 수능 성적이 매년 평균 70점, 표준편차 10점으로 일정하면 정상성 O. 매년 평균이 올라가고 있으면 정상성 X.

```
비정상 시계열:                정상 시계열:
  /\  /\                      ~∽~∽~∽~∽~
 /  \/  \  /\                 평균·분산 일정
       \/  \  /
        (추세가 있음)
```

**정상화 방법**:
1. **차분(Differencing)**: 현시점 값 - 이전시점 값. 가장 대표적.
2. **로그 변환**: 분산이 큰 데이터의 분산을 줄임. (10→1, 1000→3 으로 구간 차이 축소)
3. **평활화**: 이동평균법, 지수평활법으로 데이터를 부드럽게

📝 **보충: 지수평활법 (Exponential Smoothing) 상세**

과거 데이터에 **지수적으로 감소하는 가중치**를 부여하여 미래를 예측하는 방법이다. 최근 데이터에 더 큰 가중치를 준다.

| 종류 | 영어명 | 적용 상황 | 핵심 |
|------|--------|-----------|------|
| **단순 지수평활법** | SES (Simple ES) | 추세/계절성 **없는** 데이터 | 수준(Level)만 평활 |
| **이중 지수평활법** | Holt's Method | **추세**가 있는 데이터 | 수준 + 추세(Trend) 반영 |
| **삼중 지수평활법** | Holt-Winters Method | **추세 + 계절성** 있는 데이터 | 수준 + 추세 + 계절(Seasonal) 반영 |

**단순 지수평활법 수식**:
- F(t+1) = α × Y(t) + (1-α) × F(t)
- α (평활상수): 0~1 사이 값. α가 클수록 최근 값에 가중치↑, 변동에 민감
- α가 작으면 과거 데이터에 가중치↑, 평활 효과↑

> 💡 **직관**: "내일 예측 = α × 오늘 실제값 + (1-α) × 오늘 예측값". 오늘 실제값과 오늘 예측값을 α 비율로 섞는 것이다. α=0.9면 "오늘 실제값을 90% 반영", α=0.1이면 "기존 예측을 90% 유지". 주가처럼 빠르게 변하는 데이터는 α를 크게, 인구처럼 천천히 변하는 데이터는 α를 작게 설정한다.

```
지수평활법의 가중치 감소 패턴 (α=0.3 예시):

가중치
  |
0.30 |█████████████  ← 1일 전 (α = 0.30)
0.21 |█████████      ← 2일 전 (α(1-α) = 0.21)
0.15 |██████         ← 3일 전 (α(1-α)² = 0.15)
0.10 |████           ← 4일 전 (α(1-α)³ = 0.10)
0.07 |███            ← 5일 전 (α(1-α)⁴ = 0.07)
     +--1일--2일--3일--4일--5일--→ 과거

  → 가중치가 지수적(exponential)으로 감소! 이래서 "지수"평활법
  → 이동평균법(모든 구간에 같은 가중치)과의 핵심 차이
```

**Holt-Winters의 두 가지 모형**:
- **가법 모형(Additive)**: 계절 변동의 크기가 일정할 때 (예: 매년 12월에 매출이 100만원 증가)
- **승법 모형(Multiplicative)**: 계절 변동의 크기가 추세에 비례하여 커질 때 (예: 매년 12월에 매출이 20% 증가)

> 💡 **가법 vs 승법 구분법**: 시계열 그래프에서 계절 파동의 폭이 일정하면 가법, 시간이 갈수록 폭이 커지면(또는 작아지면) 승법이다.

⚠️ **시험 포인트**:
- "지수평활법은 최근 데이터에 더 큰 가중치를 부여한다" → 맞음
- 단순/이중/삼중의 구분 기준 = 추세와 계절성 유무
- α 값의 의미: α↑ → 최근 반영↑ → 변동에 민감, α↓ → 과거 반영↑ → 안정적

⚠️ **시험 포인트**:
- **10회 기출**: "비정상성을 가진 데이터는 차분 등의 과정으로 정상화할 수 있다" → 맞음
- 정상성의 핵심 = 모든 시점에서 일정한 평균과 분산

📝 **보충: ADF 검정 (Augmented Dickey-Fuller Test)**

시계열 데이터가 정상성을 만족하는지 통계적으로 검정하는 대표적 방법이다.

- **귀무가설(H₀)**: 단위근이 존재한다 = 비정상 시계열이다
- **대립가설(H₁)**: 단위근이 없다 = 정상 시계열이다
- **p-value < 0.05**이면 귀무가설 기각 → 정상 시계열로 판단
- p-value ≥ 0.05이면 비정상 → 차분 등으로 정상화 필요

---

### 12.3 백색잡음 (White Noise)

시계열 모형의 오차항을 백색잡음이라 부른다.
- 평균과 분산이 일정 (정상성 만족)
- 평균이 0이면 → **가우시안 백색잡음**

---

### 12.4 시계열 모형: AR, MA, ARIMA

| 모형 | 풀네임 | 핵심 아이디어 | 결정 도구 |
|------|--------|---------------|-----------|
| **AR(p)** | AutoRegressive | 자기 자신의 과거값이 미래를 결정 | **PACF** (부분자기상관함수) |
| **MA(q)** | Moving Average | 과거 오차(백색잡음)들의 선형결합 | **ACF** (자기상관함수) |
| **ARIMA(p,d,q)** | AR + I + MA | AR과 MA를 결합 + 차분 포함 | ACF + PACF |

**ARIMA(p,d,q)의 의미**:
- **p**: AR 차수 (PACF에서 결정)
- **d**: 차분 횟수 (정상화를 위해 몇 번 차분했는지)
- **q**: MA 차수 (ACF에서 결정)

**예시**:
- ARIMA(2,3,4) → AR(2), 차분 3번, MA(4)
- ARIMA(3,0,5) → d=0이므로 차분 안 함 → ARMA(3,5) 라고 부를 수 있음
- ARIMA(0,4,5) → p=0이므로 AR 없음 → IMA(4,5)
- ARIMA(3,4,0) → q=0이므로 MA 없음 → ARI(3,4)

**ACF와 PACF로 모형 결정하기**:

```
오늘과 N일 전과의 상관관계를 그래프로 그려봄:

상관성
  |█████
  |████
  |██           ← 2일 전까지 상관 높고 3일 전부터 급감
  |█
  |
  +--1일--2일--3일--4일--5일
```

- 이 그래프가 **PACF**로 그려졌으면 → **AR(2)** 모형
- 이 그래프가 **ACF**로 그려졌으면 → **MA(2)** 모형

⚠️ **시험 포인트**:
- **10회 기출**: "ARIMA는 자기회귀 + 차분 + 이동평균의 요소를 결합한 모델이다" → 맞음
- **10회 기출**: "ARIMA는 항상 비정상성을 가정한다" → 틀림. ARIMA는 차분(d)으로 **정상화한 뒤 분석**한다. 즉, 차분 후 데이터가 정상성을 만족해야 한다
- ARIMA(p,d,q)에서 d는 차분 횟수
- PACF → AR, ACF → MA 매칭 기억
- 계절성이 있으면 → **SARIMA** (앞에 S 붙임)

### 12.5 분해 시계열

**한 줄 요약**: 시계열 데이터를 4가지 요인으로 분리해서 분석하는 방법이다.

**암기법**: **추운 계절에 순환이 불규칙하다**

| 요인 | 영어 | 의미 |
|------|------|------|
| **추세** | Trend | 장기적 증가/감소 패턴 |
| **계절** | Seasonal | 특정 주기로 반복되는 패턴 |
| **순환** | Cyclical | 비주기적 장기 변동 |
| **불규칙** | Irregular | 설명 불가능한 랜덤 변동 |

⚠️ **시험 포인트**:
- 4가지 요인 외에 엉뚱한 것을 넣는 함정 문제 빈출
- 최근에는 각 요인의 특징을 세부적으로 묻는 추세
- **10회 기출**: "추운 계절의 순환이 불규칙하다" 관련 내용 출제

## 13장: 베이지안 기법

### 13.1 베이즈 정리

**한 줄 요약**: 과거 데이터(사전확률)를 바탕으로 미래(사후확률)를 예측하는 확률 공식이다.

**왜 필요한가**: 분류 문제에서 활용. 나이브 베이즈 분류 모델의 기반.

**핵심 설명**:

**예제** (고등학교 확률 문제와 동일):

> A대학에 남학생 60%, 여학생 40%. 남학생 합격률 30%, 여학생 합격률 50%.
> 합격한 신입생 중 남학생일 확률은?

**풀이 (우도표를 그리자!)**:

|  | 합격 | 불합격 | 합계 |
|--|------|--------|------|
| 남 | 0.6×0.3 = **0.18** | 0.6×0.7 = 0.42 | 0.60 |
| 여 | 0.4×0.5 = **0.20** | 0.4×0.5 = 0.20 | 0.40 |
| 합계 | **0.38** | 0.62 | 1.00 |

구하는 것: P(남|합격) = P(남∩합격) / P(합격) = 0.18 / 0.38 = **0.47**

**핵심**: 과거 정보(남녀 비율, 합격률)로 미래 정보(합격자 중 남학생 확률)를 알 수 있다!

⚠️ **시험 포인트**: 우도표를 그려서 풀면 실수를 줄일 수 있다.

---

### 13.2 나이브 베이즈 분류

**한 줄 요약**: "나이브(독립적)"라는 가정 + 베이즈 정리를 결합한 분류 모델이다.

- **나이브**: 각 특성이 서로 독립이라고 가정 → 계산이 단순해짐
- **귀납적 추론**: 이전 데이터의 확률을 기반으로 분류
- 범주에 속할 확률을 계산하여 분류

### 📝 13장 연습문제

**Q1.** 베이즈 정리에서 P(A|B) = P(B|A) × P(A) / P(B)일 때, P(A)를 무엇이라 하는가?
1. 사후확률
2. 사전확률
3. 우도(가능도)
4. 주변확률

> **정답: 2번**
> 해설: P(A)=사전확률, P(A|B)=사후확률, P(B|A)=우도(Likelihood). 베이즈 정리의 핵심은 "사전확률 × 우도 → 사후확률 업데이트".

**Q2.** 나이브 베이즈 분류기의 "나이브(Naive)"가 의미하는 것은?
1. 모든 특성의 값이 동일하다
2. 특성 간 상관관계가 매우 높다
3. 모든 특성이 서로 독립이라고 가정한다
4. 사전확률을 사용하지 않는다

> **정답: 3번**
> 해설: "나이브=순진한" → 특성들이 서로 독립이라는 **순진한 가정**을 함. 현실에서는 완벽히 독립이 아니지만, 이 가정 덕분에 계산이 빠르고 성능도 나쁘지 않음.

## 14장: 딥러닝 분석

### 14.1 심층 신경망 (DNN)

**한 줄 요약**: 은닉층이 2개 이상인 인공신경망이다.

은닉층이 깊어질수록(deep) 복잡한 패턴을 학습할 수 있다. "딥"러닝이라는 이름이 여기서 온 것.

> **[인공신경망 → 딥러닝 연결]** 5장의 MLP(다층 퍼셉트론)를 더 깊게 쌓은 것이 DNN이고, DNN을 특정 목적에 맞게 변형한 것이 CNN(이미지), RNN(시계열), 트랜스포머(범용)다. 깊게 쌓을수록 복잡한 패턴을 학습하지만, 기울기 소실/과적합 문제도 심해진다. 이를 해결하기 위해 ReLU, 드롭아웃, 배치정규화, 잔차연결(ResNet) 등이 등장했다.

### 14.2 합성곱 신경망 (CNN)

**한 줄 요약**: 이미지에서 패턴을 찾는 데 특화된 신경망이다.

**구조**:
```
이미지 → [컨볼루션 레이어] → [풀링 레이어] → [플래튼] → [FC 레이어] → 출력
          필터로 특징 추출    크기 축소        1차원 변환   DNN 구조      분류/회귀
```

📝 **보충: CNN 파이프라인 상세 ASCII**
```
[입력 이미지]      [컨볼루션+ReLU]     [풀링(Max)]       [플래튼]     [FC층]   [출력]
┌──────────┐     ┌─────────┐        ┌──────┐
│ 2 1 3 0  │     │ 8  6  4 │        │ 8  6 │        ┌──┐    ┌──┐
│ 0 4 2 1  │ →   │ 5  9  3 │   →    │ 9  7 │   →    │8 │ →  │○ │→ 강아지:0.8
│ 1 3 5 2  │     │ 4  7  6 │        └──────┘        │6 │    │○ │→ 고양이:0.2
│ 2 0 1 4  │     └─────────┘        크기 축소!       │9 │    └──┘
└──────────┘     필터가 슬라이딩      (연산량 감소)    │7 │  소프트맥스
  28×28          하며 특징 추출                       └──┘
                                                    1차원 변환

반복 가능: [Conv → ReLU → Pool] × N회 → Flatten → FC → 출력
  앞쪽 층: 단순 특징(가장자리, 색상)
  뒷쪽 층: 복잡한 특징(눈, 코, 얼굴)
```

| 레이어 | 역할 | 비유 |
|--------|------|------|
| **컨볼루션(Convolution)** | 필터로 이미지 특징 추출 | 핸드폰 사진에 필터 적용 |
| **풀링(Pooling)** | 이미지 크기 축소 → 연산량 감소 | 사진 해상도 줄이기 |
| **플래튼(Flatten)** | 2D → 1D로 펼침 | 입체를 한 줄로 나열 |
| **FC(Fully Connected)** | DNN 구조로 최종 분류/회귀 | 일반 신경망 |

**CNN의 활용**:

| 용도 | 설명 |
|------|------|
| **분류** | 이미지가 강아지인지 고양이인지 판단 |
| **객체 탐지** | 이미지 안에서 사람의 위치를 사각형으로 표시 |
| **분할(Segmentation)** | 사람 부분만 정확히 잘라냄 (배경 제거) |

⚠️ **시험 포인트**: CNN의 레이어 구조(컨볼루션→풀링→플래튼→FC) 순서 기억. 최근 세세하게 출제.

### 14.3 순환 신경망 (RNN)

**한 줄 요약**: 순차적 데이터(언어, 시계열)를 처리하기 위해 자기 자신에게 순환 연결을 가진 신경망이다.

**왜 필요한가**: 문장은 앞뒤 문맥이 중요하다. 일반 신경망은 이전 정보를 기억하지 못하지만, RNN은 이전 출력을 다시 입력으로 사용해서 문맥을 파악한다.

```
일반 신경망:  입력 → [노드] → 출력

RNN:          입력 → [노드] → 출력
                      ↑  ↓
                    (순환 연결: 이전 출력을 다시 입력으로)
```

**장기 의존성 문제**:
- 문장이 길어지면 맨 앞의 정보가 뒤로 전달되지 못함
- 비유: 강의를 3시간 들으면 처음 내용이 기억나지 않는 것과 같다
- 해결: **LSTM**, **GRU** 등 개선된 모델 등장

📝 **보충: RNN 시계열 처리 플로우 ASCII**
```
[RNN 시간 단계별 처리]
  시점1     시점2     시점3     시점4
  "나는"   "빅데이터" "분석을"  "좋아해"
    ↓         ↓         ↓         ↓
  ┌──┐  h₁  ┌──┐  h₂  ┌──┐  h₃  ┌──┐
  │h₁│ ───→ │h₂│ ───→ │h₃│ ───→ │h₄│ → 출력
  └──┘      └──┘      └──┘      └──┘
  은닉상태가 다음 시점으로 전달 (문맥 기억)

[LSTM - 장기 기억 문제 해결]
         ┌─────────── 셀 상태 (장기 기억) ──────────────┐
         │              │              │              │
  시점1  ↓    시점2     ↓    시점3     ↓    시점4     ↓
  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐
  │ 망각게이트│ │ 망각게이트│ │ 망각게이트│ │ 망각게이트│
  │ 입력게이트│ │ 입력게이트│ │ 입력게이트│ │ 입력게이트│
  │ 출력게이트│ │ 출력게이트│ │ 출력게이트│ │ 출력게이트│
  └──────────┘ └──────────┘ └──────────┘ └──────────┘

  - 망각 게이트: 어떤 정보를 잊을지 결정
  - 입력 게이트: 어떤 새 정보를 저장할지 결정
  - 출력 게이트: 어떤 정보를 출력할지 결정
  → 3개의 게이트로 장기 의존성 문제 해결!
```

📝 **보충: LSTM 게이트 단계별 상세 설명 (비유: 공부 노트 관리)**

LSTM의 핵심은 **셀 상태(Cell State)** = 장기 기억 통로이다. 3개의 게이트가 이 통로를 관리한다.

```
비유: 시험 공부 노트를 관리하는 과정

[Step 1] 망각 게이트 (Forget Gate) - "뭘 지울까?"
   → 노트에서 오래되고 불필요한 내용을 지운다
   → 시그모이드 함수로 0(완전 삭제)~1(완전 보존) 결정
   → 예: "작년 시험 범위에서 빠진 내용은 지우자"

[Step 2] 입력 게이트 (Input Gate) - "뭘 새로 적을까?"
   → 새로운 정보 중 중요한 것을 노트에 추가한다
   → 시그모이드(저장할지 말지) × tanh(후보 정보) 로 결정
   → 예: "오늘 수업에서 중요한 공식을 노트에 추가하자"

[Step 3] 셀 상태 업데이트 - "노트 갱신!"
   → 셀 상태 = (이전 셀 × 망각) + (새 정보 × 입력)
   → 불필요한 건 지우고, 새로운 건 추가한 최신 노트

[Step 4] 출력 게이트 (Output Gate) - "뭘 답안지에 쓸까?"
   → 노트 전체를 답안에 쓰는 게 아니라, 지금 문제에 필요한 부분만 출력
   → 시그모이드(출력할지 말지) × tanh(셀 상태) 로 결정
   → 예: "이 문제에는 노트의 이 부분만 써야지"
```

| 게이트 | 역할 | 활성함수 | 비유 |
|--------|------|----------|------|
| **망각 게이트** | 이전 정보 중 버릴 것 결정 | 시그모이드 | 노트에서 지우개로 지우기 |
| **입력 게이트** | 새 정보 중 저장할 것 결정 | 시그모이드 + tanh | 노트에 새 내용 적기 |
| **출력 게이트** | 현재 출력할 정보 결정 | 시그모이드 + tanh | 답안지에 쓸 내용 선택 |

> **GRU(Gated Recurrent Unit)**는 LSTM의 3개 게이트를 **2개(업데이트 게이트 + 리셋 게이트)**로 간소화했다. 업데이트 게이트=LSTM의 망각+입력 결합, 리셋 게이트=이전 정보를 얼마나 잊을지 결정. 게이트가 2개라 LSTM(3개)보다 빠르고, 성능은 비슷하다.

⚠️ **시험 포인트**:
- RNN = 순차적 데이터 특화, 순환 구조
- 장기 의존성 문제 → LSTM, GRU로 극복
- **10회 기출**: 어텐션 메커니즘 관련 출제됨

### 14.4 오토인코더 (Autoencoder)

**한 줄 요약**: 입력 데이터를 압축(인코딩)했다가 다시 복원(디코딩)하는 구조의 신경망이다.

```
입력 데이터 → [인코더: 압축] → [레이턴트 스페이스] → [디코더: 복원] → 복원된 데이터
  (크기 大)                     (크기 小)                            (크기 大)
```

| 구성 | 역할 |
|------|------|
| **인코더** | 입력을 저차원으로 압축 |
| **레이턴트 스페이스/컨텍스트 벡터** | 압축된 정보가 저장되는 공간 |
| **디코더** | 압축된 데이터를 원래 형태로 복원 |

**활용**:
- **차원축소**: 인코더 부분 활용
- **생성 모델의 기반**: 디코더 부분이 새로운 데이터를 생성
- **이상탐지**: 정상 데이터만 학습시킨 후, 비정상 데이터가 들어오면 복원이 이상하게 됨 → 이상 탐지

**생성 모델 종류**:

| 모델 | 핵심 |
|------|------|
| **VAE** | 레이턴트 스페이스에 확률 분포 도입 |
| **GAN** | 생성기(진짜 같은 이미지 생성) vs 판별기(진짜/가짜 구분)가 적대적으로 경쟁 |
| **DCGAN** | GAN + CNN 결합 |

⚠️ **시험 포인트**:
- **10회 기출**: "오토인코더는 지도학습이다" → 틀림. **비지도학습**이다 (정답 레이블 없이 입력=출력으로 학습)
- **10회 기출**: 인코더=압축, 디코더=복원, 입력과 출력은 동일한 형상
- GAN: 생성기와 판별기가 적대적(adversarial) 경쟁

📝 **보충: GAN (Generative Adversarial Network) 상세**

**한 줄 요약**: 위조범(생성기)과 경찰(판별기)이 서로 경쟁하며 실력을 키우는 구조.

**구조**:
```
랜덤 노이즈(z) → [생성기 G] → 가짜 이미지
                                    ↓
                              [판별기 D] → 진짜/가짜 판별
                                    ↑
                              진짜 이미지(학습 데이터)
```

**생성기 (Generator)**:
- 입력: 랜덤 노이즈 벡터(z) — 의미 없는 숫자 배열
- 출력: 진짜처럼 보이는 가짜 데이터(이미지 등)
- 목표: 판별기를 속이는 것 (판별기가 "진짜"라고 오판하도록)
- 구조: 업샘플링(작은 벡터 → 큰 이미지), 전치 합성곱(Transposed Convolution) 등

**판별기 (Discriminator)**:
- 입력: 진짜 이미지 또는 생성기가 만든 가짜 이미지
- 출력: 진짜일 확률 (0~1)
- 목표: 진짜와 가짜를 정확하게 구분하는 것
- 구조: 일반적인 CNN 분류 모델과 유사 (합성곱 → 풀링 → FC)

**학습 과정** (적대적 학습):
1. **판별기 학습**: 진짜 데이터 → 1(진짜), 가짜 데이터 → 0(가짜)로 학습
2. **생성기 학습**: 생성한 가짜를 판별기에 넣어 1(진짜)이 나오도록 학습
3. 1-2를 반복 → 생성기는 더 정교한 가짜를 만들고, 판별기는 더 세밀하게 구분
4. **이상적 종료**: 판별기가 진짜/가짜를 구분 못해 확률이 0.5에 수렴 (내쉬 균형)
   - 💡 **내쉬 균형 직관**: 위조범이 너무 잘 만들어서 경찰이 동전 던지기(50:50)로 판단할 수밖에 없는 상태. 어느 쪽도 일방적으로 전략을 바꿔서 이득을 볼 수 없는 균형점이다.

**GAN의 문제점**:
- **모드 붕괴(Mode Collapse)**: 생성기가 소수의 샘플만 반복 생성하는 현상
- **학습 불안정**: 생성기와 판별기의 균형이 깨지면 학습 실패
- **평가 어려움**: 생성 품질을 정량적으로 측정하기 어려움 (FID 등 사용)

**GAN 변형 모델**:
| 모델 | 특징 |
|------|------|
| **DCGAN** | CNN 구조를 적용한 GAN. 합성곱/전치합성곱 사용 |
| **CGAN** | 조건(클래스 레이블)을 부여하여 원하는 종류의 데이터 생성 |
| **CycleGAN** | 쌍이 없는 이미지 변환 (말→얼룩말 등) |
| **StyleGAN** | 고해상도 얼굴 이미지 생성에 특화 |

⚠️ **시험 포인트**: "GAN의 생성기와 판별기는 서로 적대적으로 학습한다" → 맞음. "GAN은 비지도학습이다" → 맞음 (레이블 없이 학습). 모드 붕괴의 개념도 알아둘 것.

### 14.5 시퀀스투시퀀스 (Seq2Seq) & 트랜스포머

**시퀀스투시퀀스**:
- 오토인코더 구조에 **RNN**을 적용하여 문장 번역
- 입력 길이와 출력 길이가 달라도 변환 가능
- 단점: 정보가 압축되면서 **손실 발생**, 속도 느림 (순차 처리)

**트랜스포머(Transformer)**:
- Seq2Seq + **어텐션(Attention)** 메커니즘
- 특정 중요 정보에 **집중(attention)** 할 수 있음
- **병렬 처리 가능** (RNN의 순차 처리 한계 극복)
- 정보 손실 개선
- 현재 대부분의 자연어 처리 모델의 기반 (BERT, GPT 등)

⚠️ **시험 포인트**:
- **10회 기출**: 어텐션은 "각 요소의 가중치로 중요한 정보를 강조한다" → 맞음
- **10회 기출**: 트랜스포머는 "어텐션 메커니즘을 기반으로 동작한다" → 맞음
- **10회 기출**: 셀프 어텐션은 "입력 요소들 간의 상관관계를 반영한다" → 맞음
- RNN의 장기 의존성 → 어텐션으로 해결

### 14.6 CNN vs RNN 비교표

| 항목 | CNN | RNN |
|------|-----|-----|
| **주요 입력** | 이미지, 격자형 데이터 | 시퀀스, 시계열, 텍스트 |
| **핵심 구조** | 합성곱 필터 + 풀링 | 순환 연결 (이전 출력 → 현재 입력) |
| **파라미터 공유** | 공간적 (필터를 전체 이미지에 재사용) | 시간적 (타임스텝 간 가중치 공유) |
| **장점** | 공간적 패턴 인식, 위치 불변성 | 가변 길이 시퀀스 처리 가능 |
| **단점** | 순서 정보를 무시 | 장기 의존성 문제 (기울기 소실) |
| **변형** | ResNet, VGG, Inception | LSTM, GRU, Bi-RNN |
| **활용** | 이미지 분류, 객체 탐지 | 번역, 감성분석, 주가 예측 |

⚠️ **시험 포인트**: "CNN은 시계열에 적합하다" → **틀림** (시계열은 RNN/LSTM). 둘 다 파라미터 공유를 하지만 방식이 다름 (공간 vs 시간).

📝 **보충**: CNN은 원래 이미지 특화이나, 1D-CNN으로 시계열에도 활용 가능. 다만 시계열의 기본 선택지는 RNN/LSTM이다.

## 15장: 비정형 데이터 분석

### 15.1 워드 임베딩 (Word Embedding)

**한 줄 요약**: 텍스트(자연어)를 컴퓨터가 이해할 수 있는 숫자 벡터로 변환하는 기법이다.

| 방법 | 특징 |
|------|------|
| **원핫인코딩** | 가장 기본. 메모리 낭비, 단어 간 의미 반영 못함 |
| **TF-IDF** | 문서 내 등장 빈도 + 전체 문서에서의 희소성 반영 |
| **LSA** | TF-IDF 등을 SVD로 차원축소 → 잠재 의미 추출 |
| **Word2Vec** | 단어를 벡터 공간에 배치. 비슷한 의미의 단어는 가까이 위치 |
| **GloVe** | 통계 정보 반영한 워드 임베딩 |
| **FastText** | 단어를 부분으로 쪼개서 벡터 계산 |
| **ELMo** | 양방향 문맥 반영 |

**Word2Vec 비유**: 단어들을 좌표 평면에 점으로 찍는다. "강아지"와 "고양이"는 가까운 위치에, "포도"와 "사과"도 가까운 위치에 놓인다. 의미가 비슷한 단어들이 가까이 모인다.

⚠️ **시험 포인트**: (💡 2025ver 보충) Word2Vec은 시험에 출제된 적 있음. 원핫인코딩의 한계(메모리 낭비, 의미 미반영)도 기억.

### 15.2 기타 비정형 데이터 분석

| 기법 | 설명 |
|------|------|
| **소셜 네트워크 분석** | 사람 간 관계를 그래프로 표현하여 분석 |
| **감정 분석** | 텍스트의 감정(긍정/부정) 판단 |
| **오피니언 마이닝** | 의견 추출 및 분석 |
| **리얼리티 마이닝** | 기계/센서의 실제 비정형 데이터 추출·분석 |

📝 **보충**: (💡 2025ver 보충) 유전자 알고리즘의 세부 내용도 시험 어려워지면 출제 가능성 있음. 시간 되면 학습 권장.

📝 **보충: 텍스트 마이닝 상세**

**TF-IDF (Term Frequency - Inverse Document Frequency)**:
- **TF**: 특정 문서에서 해당 단어가 많이 나올수록 높음
- **IDF**: 전체 문서에서 해당 단어가 드물게 나올수록 높음
- **TF-IDF = TF × IDF**: 특정 문서에서 중요한 단어일수록 값이 높음
- 비유: "the"는 모든 문서에 많이 나옴 → IDF 낮음 → TF-IDF 낮음. "인공지능"은 특정 문서에만 많이 나옴 → TF-IDF 높음

**토픽 모델링 (Topic Modeling)**:

문서 집합에서 숨겨진 **주제(토픽)**를 자동으로 발견하는 비지도학습 기법이다.

**LDA (Latent Dirichlet Allocation)**:
- 토픽 모델링의 대표적 알고리즘
- 각 **문서**는 여러 토픽의 **혼합(mixture)**으로 구성된다고 가정
- 각 **토픽**은 여러 단어의 **확률 분포**로 구성된다고 가정
- 비유: 뉴스 기사 하나가 "경제 60% + 정치 30% + IT 10%"처럼 여러 주제를 섞어서 다루고, "경제" 토픽에는 "금리, 환율, 주가" 같은 단어가 높은 확률로 등장

**LDA 작동 원리** (간략):
1. 토픽 수(K)를 미리 설정 (하이퍼파라미터)
2. 각 문서의 단어에 랜덤으로 토픽 할당
3. 반복적으로 토픽 할당을 갱신:
   - 이 문서에서 이 토픽이 얼마나 많은가?
   - 이 단어가 이 토픽에서 얼마나 자주 나오는가?
4. 수렴할 때까지 반복 → 각 문서의 토픽 분포, 각 토픽의 단어 분포 도출

```
LDA 구조 다이어그램 (K=3 토픽 예시):

  [문서1: AI 뉴스]         [문서2: 요리 블로그]      [문서3: AI 요리 로봇]
   ┌──────────┐            ┌──────────┐            ┌──────────┐
   │ IT  80%  │            │ 요리 90% │            │ IT  40%  │
   │ 경제 15% │            │ 건강  5% │            │ 요리 50% │
   │ 요리  5% │            │ IT   5%  │            │ 경제 10% │
   └────┬─────┘            └────┬─────┘            └────┬─────┘
        │                       │                       │
        ▼                       ▼                       ▼
  ┌─────────────────────────────────────────────────────────┐
  │  토픽 "IT"    → {인공지능:0.3, 데이터:0.2, 알고리즘:0.15, ...}  │
  │  토픽 "요리"  → {레시피:0.25, 재료:0.2, 맛:0.15, ...}          │
  │  토픽 "경제"  → {금리:0.2, 환율:0.18, 주가:0.15, ...}          │
  └─────────────────────────────────────────────────────────┘

  핵심: 문서 = 토픽의 혼합, 토픽 = 단어의 확률 분포
```

**LDA vs LSA 비교**:
| 비교 | LSA | LDA |
|------|-----|-----|
| 방법 | TF-IDF + SVD(행렬 분해) | 확률적 생성 모델 |
| 해석 | 수학적 차원축소 | 토픽별 단어 분포로 해석 용이 |
| 출력 | 잠재 의미 벡터 | 문서별 토픽 비율 + 토픽별 단어 확률 |

⚠️ **시험 포인트**: "LDA는 각 문서가 여러 토픽의 혼합이라고 가정한다" → 맞음. LDA에서 토픽 수(K)는 사용자가 지정하는 하이퍼파라미터. "LDA는 비지도학습이다" → 맞음.

**감성분석(Sentiment Analysis)**:
- 텍스트에서 감성(긍정/부정/중립)을 자동으로 판별
- 활용: 상품 리뷰 분석, SNS 여론 조사, 고객 불만 탐지
- 방법: 사전 기반(감성 사전 활용), 머신러닝 기반(학습 데이터로 분류 모델 구축)

## 16장: 앙상블 분석

### 16.1 앙상블의 개념

**한 줄 요약**: 여러 모델을 조합해서 하나의 더 좋은 결과를 만드는 기법이다.

> **[의사결정나무 → 앙상블 연결]** 의사결정나무 하나는 해석이 쉽지만 과적합이 심하고 불안정하다(데이터가 조금만 바뀌어도 트리 구조가 크게 달라짐). 이 약점을 극복하기 위해 "나무를 여러 개 만들어서 투표하면?"이라는 아이디어가 앙상블이다. 배깅은 **분산을 줄이고**, 부스팅은 **편향을 줄여서** 단일 모델보다 훨씬 좋은 성능을 낸다.

비유: 오케스트라에서 바이올린, 첼로, 플루트 등 여러 악기가 합쳐져서 더 풍성한 하모니를 만드는 것처럼, 여러 모델을 조합하면 개별 모델보다 더 좋은 성능을 낸다.

---

### 16.2 앙상블 기법 총정리

#### 보팅 (Voting)
- 여러 모델의 결과를 **투표**로 결정
- **하드 보팅**: 다수결 (예측 클래스 자체로 투표)
- **소프트 보팅**: 확률의 평균으로 결정 → 일반적으로 **성능이 더 좋음**

#### 배깅 (Bagging = Bootstrap Aggregating)
1. 원본 데이터에서 **복원추출**로 여러 부분집합(부트스트랩) 생성
2. 각 부트스트랩으로 모델 학습
3. 결과를 **보팅**으로 종합

```
원본 데이터
  ├─ 복원추출 → 부트스트랩1 → 모델1 ─┐
  ├─ 복원추출 → 부트스트랩2 → 모델2 ─┼─ 보팅 → 최종 결과
  └─ 복원추출 → 부트스트랩3 → 모델3 ─┘
```

**OOB (Out-of-Bag) 데이터**:
- 복원추출을 무한히 반복해도, 특정 데이터가 부트스트랩에 포함되지 않을 확률 = **36.8%**
- 수식: (1 - 1/n)^n → n→∞ → 1/e ≈ 0.368
- 이 36.8% 데이터는 학습에 사용되지 않았으므로 → **검증/평가 데이터로 활용 가능!**
- 데이터 분할 개념과 연결됨

⚠️ **시험 포인트**: OOB 36.8%는 시험에 자주 출제. 의미(학습에 미사용 → 평가에 활용)까지 이해해야 함.

#### 랜덤 포레스트 (Random Forest)
- **배깅 + 의사결정나무** 조합
- 의사결정나무의 과적합 문제를 배깅으로 해결
- **분산 감소** 효과
- 이상치에 강건
- 의사결정나무(화이트박스) → 랜덤 포레스트(**블랙박스**) 로 변환됨
- 실무에서 가장 많이 쓰이는 모델 중 하나

#### 부스팅 (Boosting)
- 이전 모델이 **잘못 분류한 데이터에 가중치**를 더 줘서 다음 모델을 학습
- **순차적**으로 학습 → 병렬 처리 불가

```
데이터 → 모델1 학습 → 오분류 데이터에 가중치↑ → 모델2 학습 → ... → 최종 결합
```

📝 **보충: 배깅 vs 부스팅 동작 구조 비교 ASCII**
```
[배깅 (Bagging)] - 독립적, 병렬 학습
  원본 데이터
  ├── 복원추출 → 샘플1 → 트리1 ──┐
  ├── 복원추출 → 샘플2 → 트리2 ──┼── 다수결 보팅 → 최종 결과
  ├── 복원추출 → 샘플3 → 트리3 ──┤   (각 트리가 독립적으로 학습)
  └── 복원추출 → 샘플4 → 트리4 ──┘

[부스팅 (Boosting)] - 순차적, 오차 집중 학습
  데이터 → 트리1 → 틀린 것에 가중치↑ → 트리2 → 틀린 것에 가중치↑↑ → 트리3
           ↓              ↓                ↓
         약한 분류기    더 강한 분류기   더더 강한 분류기
                                                  ↓
                                        가중합 → 최종 결과

[스태킹 (Stacking)] - 메타학습기 활용
  데이터 → SVM   → 예측A ──┐
  데이터 → KNN   → 예측B ──┼── [메타학습기(로지스틱 등)] → 최종 결과
  데이터 → 랜포  → 예측C ──┘
           (1단계 모델들)       (2단계: 1단계 예측을 입력으로 학습)
```

**부스팅의 종류** (시험 출제됨):
- AdaBoost
- Gradient Boosting
- XGBoost
- LightGBM
- CatBoost

📝 **보충: 랜덤포레스트 vs XGBoost vs LightGBM vs CatBoost 비교**

| 항목 | 랜덤포레스트 | XGBoost | LightGBM | CatBoost |
|------|-------------|---------|----------|----------|
| 기반 | 배깅 | 부스팅(Gradient) | 부스팅(Gradient) | 부스팅(Gradient) |
| 학습 방식 | 병렬 | 순차적 | 순차적 | 순차적 |
| 트리 성장 | 수평 (Level-wise) | 수평 (Level-wise) | **수직 (Leaf-wise)** | 수평 |
| 속도 | 보통 | 보통 | **매우 빠름** | 보통 |
| 범주형 변수 | 인코딩 필요 | 인코딩 필요 | 인코딩 필요 | **자동 처리** |
| 과적합 | 강건 | 규제 내장 | 과적합 위험 | 규제 내장 |
| 핵심 장점 | 안정적, 해석 쉬움 | 높은 성능 | 빠른 속도 | 범주형 자동 처리 |

- **Level-wise(수평)**: 같은 깊이의 노드를 모두 분할 → 균형 잡힌 트리
- **Leaf-wise(수직)**: 가장 손실이 큰 리프 노드를 우선 분할 → 비균형 트리, 더 빠름

#### 스태킹 (Stacking)
- 여러 모델의 예측 결과를 **새로운 모델(메타학습기/블렌더)의 입력**으로 사용

```
모델A → 결과A ─┐
모델B → 결과B ─┼─ [메타학습기] → 최종 결과
모델C → 결과C ─┘
```

### 16.3 앙상블 기법 비교표

| 기법 | 학습 방식 | 병렬 처리 | 핵심 특징 |
|------|-----------|-----------|-----------|
| **보팅** | 독립 | **가능** | 다수결/확률평균 |
| **배깅** | 독립 (복원추출) | **가능** | 부트스트랩 + 보팅 |
| **랜덤포레스트** | 독립 | **가능** | 배깅 + 의사결정나무 |
| **부스팅** | **순차적** (이전 결과 필요) | **불가** | 오분류에 가중치 |
| **스태킹** | 1단계 독립, 2단계 순차 | 부분 가능 | 메타학습기 활용 |

⚠️ **시험 포인트**:
- **10회 기출**: "배깅은 분산을 줄인다, 부스팅은 편향을 줄인다" → 맞음
- 보팅/배깅/랜덤포레스트 = 병렬 가능, 부스팅 = 병렬 불가 (매우 중요)
- 랜덤포레스트 = 배깅 + 의사결정나무
- 부스팅은 순차적으로 오차를 개선
- **10회 기출**: "약한 학습기를 순차적으로 학습시켜 오차를 줄이는 기법" = 부스팅

## 📝 전체 체크리스트

### 회귀분석
- [ ] 최소제곱법의 원리를 설명할 수 있는가?
- [ ] R²(결정계수)의 의미와 범위를 알고 있는가?
- [ ] SST = SSR + SSE 관계를 이해하는가?
- [ ] 리지(L2) vs 라쏘(L1)의 차이를 설명할 수 있는가?
- [ ] 다중공선성의 진단(VIF≥10)과 해결법을 아는가?
- [ ] 회귀계수 검정=t검정, 모형 검정=F검정 을 구분하는가?

### 로지스틱 회귀
- [ ] 오즈 → 로짓 변환 → 시그모이드의 흐름을 이해하는가?
- [ ] 최대우도법과 최소제곱법의 차이를 아는가?

### 의사결정나무
- [ ] 지니 지수 계산을 할 수 있는가?
- [ ] 가지치기의 목적(과적합 방지)을 아는가?
- [ ] 화이트박스 모델임을 기억하는가?

### 인공신경망
- [ ] 활성함수(시그모이드/tanh/ReLU)의 특징과 진화 순서를 아는가?
- [ ] 기울기 소실 문제와 ReLU의 관계를 설명할 수 있는가?
- [ ] 순전파/역전파/경사하강법의 순서를 이해하는가?
- [ ] 파라미터 vs 하이퍼파라미터를 구분하는가?
- [ ] 과적합 방지 방법 5가지를 말할 수 있는가?

### SVM
- [ ] 초평면, 서포트벡터, 마진의 개념을 아는가?
- [ ] 커널 함수의 역할을 설명할 수 있는가?
- [ ] 하드 마진 vs 소프트 마진 차이를 아는가?

### 앙상블
- [ ] 배깅 vs 부스팅의 핵심 차이(병렬/순차, 분산/편향)를 아는가?
- [ ] 랜덤포레스트 = 배깅 + 의사결정나무를 기억하는가?
- [ ] OOB 36.8%의 의미를 설명할 수 있는가?

### 군집분석
- [ ] K-Means vs DBSCAN 비교표를 채울 수 있는가?
- [ ] 덴드로그램에서 군집 수를 세는 방법을 아는가?
- [ ] 거리 측정 방법(유클리디안, 맨해튼, 마할라노비스)을 구분하는가?

### 시계열
- [ ] 정상성과 차분의 관계를 아는가?
- [ ] ARIMA(p,d,q)에서 각 파라미터의 의미를 아는가?
- [ ] 분해 시계열의 4요인(추운 계절에 순환이 불규칙하다)을 외우는가?

### 연관분석
- [ ] 지지도/신뢰도/향상도를 계산할 수 있는가?
- [ ] 향상도 > 1, = 1, < 1의 의미를 아는가?

### 기타
- [ ] 나이브 베이즈: 독립 가정 + 베이즈 정리 조합임을 아는가?
- [ ] CNN 구조(컨볼루션→풀링→플래튼→FC)를 순서대로 말할 수 있는가?
- [ ] RNN의 장기 의존성 문제와 LSTM/GRU를 아는가?
- [ ] 오토인코더가 비지도학습임을 아는가?
- [ ] 비모수 검정 기법을 3가지 이상 말할 수 있는가?

### 📝 보충 체크리스트
- [ ] 규제 회귀(릿지/라쏘/엘라스틱넷)의 수식과 선택 기준을 아는가?
- [ ] 의사결정나무 알고리즘(ID3/C4.5/CART/CHAID)의 차이를 구분하는가?
- [ ] 차원의 저주 개념과 해결법을 설명할 수 있는가?
- [ ] 랜덤포레스트 vs XGBoost vs LightGBM 차이를 아는가?
- [ ] ADF 검정의 귀무가설/대립가설을 아는가?
- [ ] TF-IDF의 의미와 Word2Vec의 개념을 아는가?
- [ ] 드롭아웃, 배치 정규화, 전이학습의 개념을 아는가?
- [ ] GMM(가우시안 혼합 모델)과 K-Means의 차이를 아는가?
- [ ] LSTM의 3가지 게이트(망각/입력/출력)를 설명할 수 있는가?
- [ ] 지수평활법 단순/이중/삼중의 적용 조건(추세/계절성 유무)을 구분하는가?
- [ ] 토픽모델링(LDA)에서 문서=토픽 혼합, 토픽=단어 분포임을 아는가?
- [ ] 다항회귀는 파라미터에 대해 선형임을 아는가? (비선형 회귀와 구분)
- [ ] PCR vs PLS의 핵심 차이(종속변수 반영 여부)를 아는가?
- [ ] GAN의 생성기/판별기 구조와 적대적 학습 과정을 설명할 수 있는가?
- [ ] FP-Growth가 후보 생성 없이 트리 기반으로 동작함을 아는가?

### 📝 강화 체크리스트 (알고리즘 선택 능력)
- [ ] 주어진 상황에서 지도/비지도 학습을 구분할 수 있는가?
- [ ] "해석 필요 vs 성능 중시" 상황에서 화이트박스/블랙박스를 선택할 수 있는가?
- [ ] 데이터 크기, 변수 수, 이상치 유무에 따라 적합한 알고리즘을 추천할 수 있는가?
- [ ] 이미지→CNN, 시계열→LSTM, 텍스트→트랜스포머 매칭이 자동으로 떠오르는가?
- [ ] 엘보 메소드로 최적 K를 결정하는 원리를 설명할 수 있는가?
- [ ] SVM의 C, gamma, 커널 종류(선형/RBF/다항식)의 역할을 아는가?
- [ ] 배깅=분산 감소, 부스팅=편향 감소를 상황에 적용할 수 있는가?
- [ ] 연관분석 지지도/신뢰도/향상도를 표 없이 계산할 수 있는가?

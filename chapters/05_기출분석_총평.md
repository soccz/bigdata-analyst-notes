### 합격률 관련 언급사항

- 시험 직후 "어렵다, 떨어졌다"는 반응이 많지만, 실제 합격률은 크게 내려가지 않는 패턴이 반복됨
- **100점 맞는 시험이 아니라 60점만 넘으면 되는 시험** -- 40%를 틀려도 합격
- 10회의 경우 "9회보다 훨씬 무난했다"는 여론이 지배적이었고, 이런 분위기는 강의자도 처음 본 수준
- 시험 후 불안해하다가 발표일에 합격하는 사례가 매우 많음

### 전체 출제 트렌드

1. **기출 재출제 비율이 높다**: 기출과 동일하거나 약간 변형된 문제가 상당히 많이 출제됨
2. **개념 이해 중심으로 전환**: 11회부터 "문제은행식 암기"로는 풀기 어려운 문제 증가. 개념을 정확히 이해해야 풀 수 있도록 출제
3. **딥러닝 심화 확대**: 9회부터 CNN, RNN, 오토인코더, GAN, 시퀀스투시퀀스, 트랜스포머, 어텐션 메커니즘 등 깊은 내용 출제 시작
4. **통계 심화 문제 등장**: 깁스 샘플링, 표본분산의 MSE 유도 등 전공자 수준 문제 간헐적 출제
5. **시각화는 센스 영역**: 단순 분류 암기가 아니라 논리적 접근이 필요

## 1과목: 빅데이터 분석 기획

### 자주 출제되는 주제

- 빅데이터 분석 기술 (NoSQL, 분산처리, OLTP/OLAP 구분)
- 분석 조직 구조 (집중형, 기능형, 분산형) 각각의 특징과 장단점
- 개인정보 보호법 관련 (비식별화, 익명화, 가명정보, 최소수집 원칙, 책임 원칙)
- 데이터 분석 프로젝트 수행 순서 (비즈니스 이해 -> 정의 -> 계획 수립 -> 위험 계획)
- 데이터 유형 (정형, 반정형, 비정형)의 정의와 특성
- 데이터 웨어하우스 4대 특징 (주제 지향성, 통합성, 시계열성, 비휘발성)
- WBS (프로젝트 수행 계획 수립 단계에서 작성)
- 데이터 품질 요소 (유효성, 완전성, 일관성, 정확성)
- 분석 과정의 개념 매칭 (통찰/최적화/솔루션/발견)
- 인공지능 분류 (약/강/초 인공지능)
- 데이터 사이언티스트의 역할
- FGI (포커스 그룹 인터뷰): 소수 전문가/실무자 그룹의 심층 토론

### 주의해야 할 함정

1. **"반드시", "항상" 같은 절대적 표현**: 객관식에서 이런 표현이 나오면 높은 확률로 틀린 보기
   - 예: "개인정보 보호는 반드시 익명화되어야 한다" -> 익명화는 선택 가능한 방법일 뿐
   - 예: "인공지능은 별도의 학습 없이도 문제에 대응할 수 있다" -> 학습은 필수

2. **비슷한 개념 구분 문제**: 집중형 vs 분산형 조직, 정형 vs 반정형 데이터 등 헷갈리기 쉬운 개념 쌍

3. **반정형 데이터의 특성**: "구조 변경이 어렵다"는 틀린 설명. XML, JSON 같은 태그 기반 데이터는 구조 변경 가능

### 10회 기출 복원 문제 + 상세 해설

**Q1. 빅데이터 분석 기술에 대한 설명으로 옳지 않은 것은?**

1. NoSQL은 비정형 데이터 저장 및 처리를 지원한다
2. 분산 처리는 대용량 데이터를 효율적으로 병렬 처리할 수 있도록 한다
3. JDBC/OLTP는 대용량 비정형 데이터 분석에 적합한 기술이다
4. 빅데이터 분석은 정형, 반정형, 비정형 데이터 모두 처리할 수 있어야 한다

**정답: 3번**

> JDBC와 OLTP는 관계형 DBMS(RDBMS)에 있는 데이터를 처리/분석하기 위한 기술이다. 대용량 비정형 데이터를 분석하는 기술이 아니다. NoSQL이 비정형 데이터에 적합한 기술이며, 분산처리는 대용량 데이터의 병렬 처리를 담당한다.

---

**Q2. 집중형 조직 구조에 대한 설명으로 옳지 않은 것은?**

1. 별도의 부서를 구성하여 전문적으로 관리한다
2. 현업 부서에 빠르게 적용하고 확산하기에 유리하다
3. 조직과 현업부서가 역할을 분리한다
4. 업무의 표준화, 일반적인 통합 관리가 가능하다

**정답: 2번**

> 현업 부서에 빠르게 적용하고 확산하려면 해당 부서에 분석 인력이 배치되어 있어야 유리하다. 이것은 **분산형** 조직의 특징이다. 집중형은 별도 분석 조직을 두고 전문적으로 관리하는 구조다.

---

**Q3. 개인정보 보호에 대한 설명으로 옳지 않은 것은?**

**정답: 1번** -- "개인정보 보호는 반드시 익명화되어야 한다"

> 익명화는 선택 가능한 방법 중 하나일 뿐, 필수가 아니다. "반드시"라는 절대적 표현에 주의해야 한다.

**Q4. 책임 원칙 위반에 해당하는 사례는?**

**정답: 3번** -- "실제 신용도와 무관하게 대출 불이익을 주는 경우"

> 책임 원칙 위반은 "범죄가 발생하지 않았는데 체포하는 상황"과 유사한 개념이다. 실제 결과와 무관하게 미리 불이익을 주는 것이 핵심이다.

**Q5. 데이터 분석 프로젝트 수행순서로 올바른 것은?**

**Q6. 총계 처리(비식별화 기법)에 대한 설명으로 틀린 것은?**

1. 통계값을 적용하여 개인식별이 어렵도록 한다
2. 데이터를 재배열하면 개인 식별이 불가능하다
3. 데이터 수가 적으면 개인 식별 가능성이 높아진다
4. 총계 처리된 데이터는 개인 단위 수치 계산이 가능하다

**정답: 4번**

> 총계 처리 데이터는 **집계된 수치만** 제공한다. 개인 단위로 역추산하여 계산하는 것은 불가능하다.

**Q7. 데이터 유형에 대한 설명으로 틀린 것은?**

**정답: 3번** -- "반정형 데이터는 구조 변경이 어렵다"

> 반정형 데이터(XML, JSON 등)는 태그(메타데이터)를 활용하여 구조 변경이 가능하다.

**Q9. 데이터 수집 기술과 수집 대상의 연결이 틀린 것은?**

## 2과목: 빅데이터 탐색

### 자주 출제되는 주제

- **표본추출 방법**: 층화추출, 군집추출, 단순무작위추출의 구분 및 적용 상황
- **확률분포**: 이항분포(평균 np, 분산 np(1-p)), 초기하분포(비복원 추출), 정규분포
- **기술통계**: Z-점수 계산, 왜도(skewness), 박스플롯의 구성요소
- **상관계수**: 피어슨(선형, 이상치에 약함) vs 스피어만(순위, 이상치에 강함)
- **공분산**: 공분산이 0이면 독립? (선형 관계만 측정하므로 비선형 관계가 있을 수 있음)
- **점추정과 구간추정**: 불편추정량 개념, 점추정 후 구간추정 수행
- **변수 선택 기법**: 카이제곱, F-검정, 상호정보량 (평균값은 변수 선택에 사용 안 됨)
- **파생 변수 vs 요약 변수**: 파생 변수는 논리적 타당성/주관 개입, 요약 변수는 집계(합계, 평균 등)
- **교차 검증의 목적**: 일반화 성능 평가
- **데이터 정제**: 이상치, 결측치 처리로 데이터 품질을 높이는 작업
- **샘플링 기법**: 오버샘플링, 언더샘플링, SMOTE의 정의와 차이
- **LSA (Latent Semantic Analysis)**: SVD를 통한 텍스트 데이터 차원 축소

### 주의해야 할 함정

1. **표본 평균의 "기대값"과 "표본 평균" 자체를 혼동하지 말 것**
   - "표본 평균의 기대값은 모평균과 같다" -> 맞는 말 (불편추정량의 정의)
   - "표본 평균은 모평균과 항상 일치한다" -> 틀린 말 (기대값이 없으면 다른 개념)

2. **공분산 = 0이면 독립이다?** -> 틀림!
   - 공분산은 **선형 관계**만 측정. 2차 함수 등 비선형 관계가 있어도 공분산이 0일 수 있음
   - "X, Y가 독립이면 공분산은 0" -> 맞음 (역은 성립 안 함)

3. **표본 분산 vs 모집단 분산**: "표본 분산은 모집단 분산보다 항상 크다" -> 틀림. 반례를 들 수 있음 (모집단 {1,2,3,4,5}에서 표본 {2,3,4}를 뽑으면 표본 분산이 더 작음)

4. **피어슨 상관계수의 한계**: 상관계수가 0이라고 "연관이 없다"고 할 수 없음. 비선형 관계도 연관이 있지만 상관계수는 0이 나올 수 있음

5. **"유의하다"는 p-value로 판단**: 상관계수 값이 0.5 이상이든 아니든, 유의한지 여부는 p-value(T-검정)를 통해 판단하는 것이지 상관계수 값 자체로 결정하는 것이 아님

**Q25. X1, X2가 각각 1일 확률 p, -1일 확률 (1-p)일 때, Y = (X1+X2)/2가 -1, 0, 1이 될 확률은?**

**정답: 2번** -- Y=1: p², Y=0: 2p(1-p), Y=-1: (1-p)²

> - Y=0이 되려면 (X1=1, X2=-1) 또는 (X1=-1, X2=1) -> 확률 = p(1-p) + (1-p)p = 2p(1-p)

## 3과목: 빅데이터 모델링

### 자주 출제되는 주제

- **경사하강법**: 배치/확률적/미니배치 경사하강법의 차이, 학습률, 모멘텀
- **서포트 벡터 머신(SVM)**: 커널 트릭, 마진, 서포트 벡터, 초평면, 편향(오프셋)
- **의사결정나무**: 분류/회귀 모두 가능, 가지치기(과적합 방지), 화이트박스 모델
- **앙상블**: 배깅(분산 감소) vs 부스팅(편향 감소)
- **주성분분석(PCA)**: 분산이 큰 축부터 선택, 축은 서로 직교(독립)
- **신경망**: 활성함수(ReLU, 시그모이드), 과적합 방지(드롭아웃, 조기종료, 정규화)
- **딥러닝 심화**: CNN(이미지), RNN(시계열/자연어), 오토인코더, 시퀀스투시퀀스, 어텐션, 트랜스포머
- **로지스틱 회귀**: 오즈비, 로짓 변환, 분류 문제
- **라쏘(L1) vs 리지(L2)**: 라쏘는 계수를 0으로 만듦(변수 선택 효과), 리지는 0에 가깝게만 만듦
- **하이퍼파라미터 vs 파라미터**: 하이퍼파라미터는 사용자 설정, 파라미터(가중치)는 학습으로 자동 조정
- **과적합과 과소적합**: 학습/검증 오차 곡선 해석, 방지 방법
- **모델 평가**: 정밀도, 재현율, F1-score, MSE, RMSE, MAPE

### 주의해야 할 함정

1. **배치 경사하강법의 "크기" vs "개수"**: 데이터 n개일 때, 배치 경사하강법의 미니배치 **크기**는 n, **개수**는 1. 확률적 경사하강법은 크기 1, 개수 n. 문제에서 "크기"를 물었는지 "개수"를 물었는지에 따라 답이 달라짐

2. **커널 트릭 없는 SVM = 선형 분류기**: SVM의 핵심 강점은 커널 함수를 통한 비선형 분류. 커널이 없으면 선형만 가능

3. **ReLU는 과적합 방지 기법이 아니다**: ReLU는 활성함수로서 비선형 문제 해결 및 기울기 소실 문제 방지 목적. 과적합 방지는 드롭아웃, 조기종료, 정규화 등

4. **"독립변수를 비선형 변환하면 분류 효율이 상승한다"**: 틀림. SVM에서 커널 함수가 알아서 해주며, 독립변수를 직접 비선형 변환할 필요 없음

3. ARIMA는 자기회귀(AR), 차분(I), 이동평균(MA)의 요소를 결합한 모델이다
4. 항상 비정상성을 가정하고 모델을 구성한다

**정답: 4번**

> ARIMA는 **정상성**을 가정한다. 그래서 비정상 데이터를 정상화시키기 위해 차분(I, Integration)을 수행하는 것이다. "항상 비정상성을 가정"은 정반대의 설명이다.

## 4과목: 빅데이터 결과 해석

### 자주 출제되는 주제

- **시각화 유형 분류**: 관계 시각화(산점도, 버블차트, 히트맵) vs 비율 시각화(파이차트) vs 비교 시각화 등
- **인포그래픽**: 정보(Information) + 그래픽(Graphic)의 결합, 데이터 시각화와 별개 개념
- **지도 시각화**: 단계구분도(색상 구간), 카토그램(면적 왜곡), 지오코딩(주소->좌표)
- **학습 곡선 해석**: 훈련/검증 오차 수렴 패턴, 과적합/과소적합 판단
- **과적합 판단**: 훈련 오차 감소 + 검증 오차 증가 = 과적합
- **모델 평가 지표**: 리콜(재현율/민감도), 정밀도, F1-score, MSE, RMSE, MAPE
- **홀드아웃 검증**: 데이터를 일정 비율로 분리(train/test)
- **LOOCV**: 데이터 수가 적을 때, 검증에 1개만 사용
- **그리드 탐색**: 모든 하이퍼파라미터 조합을 체계적으로 탐색
- **로지스틱 회귀 결과 해석**: 회귀계수 부호(양/음), p-value 유의성, 잔차 편차
- **과적합 방지**: 데이터 증가, 모델 단순화, 정규화, 규제 강도 높이기

### 주의해야 할 함정

1. **관계 시각화 분류**: K-데이터에서 시공간/관계/비교 3가지로만 분류하다 보니 파이차트도 관계 시각화에 포함되는 교재가 많음. 하지만 **"가장 옳지 않은 것"을 고르라면 파이차트**가 답 (파이차트는 비율 관계, 나머지는 상관관계를 보여줌)
2. **단계구분도는 연속형 데이터를 "정확하게" 표현하지 못함**: 계단형(이산적) 색상 구간을 사용하기 때문
3. **학습 곡선이 수렴해도 학습 진행은 가능**: 수렴 후 계속 학습하면 성능이 나빠질 수 있지만, 물리적으로 학습 "진행"은 가능함
4. **MAPE는 퍼센트 표현**: 공식에 ×100이 포함됨

> ⚠️ **복원 주의**: 위 보기 3번 "지역 최소값에 빠질 위험이 있다"는 사실 **맞는 설명**이다. SGD는 실제로 지역 최소값에 빠질 수 있다. 원래 시험 보기는 **"지역 최소값에 빠질 위험이 없다"** 등 반대 표현이었을 가능성이 높다. 복원 과정에서 표현이 바뀐 것으로 보임.
>
> **핵심 학습 포인트**: SGD는 지역 최소값에 빠질 수 **있으나**, 확률적 특성(노이즈) 덕분에 탈출 가능성도 있다. 이를 개선한 것이 Momentum, Adam 등.

> SGD는 데이터를 하나씩(또는 작은 배치로) 처리하므로 **지역 최소값에 빠질 위험이 있다**. 이를 극복하기 위해 모멘텀, AdaGrad 등의 최적화 기법이 등장했다. 온라인 학습(데이터가 순차적으로 들어오는 환경)에도 적합하다.

3. **3과목 (빅데이터 모델링)** -- 딥러닝까지 커버

   - 활성함수(ReLU vs 시그모이드), 과적합 방지 기법 반복 출제

4. **4과목 (빅데이터 결과 해석)** -- 센스 + 기본 암기

   - 모델 평가 지표(정밀도, 재현율, F1, MSE, RMSE, MAPE) 공식 반드시 암기
   - 학습 곡선 해석, 과적합/과소적합 판단 패턴 숙지

## 부록: 9회/11회 총평에서 언급된 추가 논란 문제 정리

### 9회 주요 논란 문제

**시퀀스투시퀀스(Seq2Seq) 관련**
- RNN 기반 + 오토인코더 구조. 문장 길이에 상관없이 활용 가능하지만, RNN 기반이므로 문장이 길어지면 성능 저하
- 컨텍스트 벡터 사용. 이를 보완하기 위해 트랜스포머가 등장
- 시험에 "가나다" 보기가 없고 "가다"만 있어서 난이도가 낮았지만, 다음 시험에는 "나"도 포함될 수 있으니 주의

**데이터 품질 6가지 속성 (TTA 표준)**
- 정확성, 일관성, 유용성, 접근성, 적시성(Timeliness), 보안성
- "불편의성(Unbiasedness)"은 이 6가지에 포함되지 않음
- "적시성"과 "시의성"은 번역의 차이일 뿐 같은 개념 (Timeliness)

**계층적 군집분석의 군집 변경 불가**
- 계층적 군집분석은 가까운 것끼리 순차적으로 묶어나감
- 한번 특정 군집에 속하면 **변경 불가** (군집의 규모가 커질 뿐)
- K-means는 반복 과정에서 군집 변경 가능 (혼동 주의)

**SVM의 초평면과 오프셋**
- 마진(margin)은 초평면과 직교하는 것 맞음
- 초평면의 오프셋(위치)을 결정하는 것은 **편향(bias)**
- 커널 함수는 비선형 변환을 담당하는 것이지 오프셋과는 무관

**MDS vs t-SNE**
- MDS: **로컬 최소**를 보장 (글로벌 최소 보장 못함)
- t-SNE: 로컬에 더 집중하지만 글로벌도 어느 정도 봄
- "MDS가 글로벌 최소를 보장한다"는 **틀린 설명**

**동질성 검정을 위한 추출 방법**
- 동질성 검정: 여러 모집단의 특성이 비슷한지 검정
- **층화 추출**이 유리: 만족/불만족 같은 층으로 나눠서 각각 추출
- 군집 추출은 데이터가 섞여버리므로 부적절

### 11회 주요 논란 문제

**배치/확률적 경사하강법의 미니배치 크기 vs 개수**
- 데이터 n개일 때:
  - 배치 경사하강법: 미니배치 크기=n, 개수=1
  - 확률적 경사하강법: 미니배치 크기=1, 개수=n
- "크기"를 물었느냐, "개수"를 물었느냐에 따라 답이 달라지므로 문제를 정확히 읽어야 함

**슬라이딩 윈도우의 사용 목적**
- 핵심 목적: 시계열 데이터에서 특정 구간만 확인하여 **패턴 탐지**
- 무빙 에버리지(이동 평균)를 통해 이상치 제거도 가능하지만, 이것은 부가 기능
- "가장 적절한 것"을 고르라면 시계열 패턴 탐지가 원래 목적

**시계열 데이터 - ACF의 역할**
- ACF(자기상관함수): 현재 시점과 과거 시점 간의 상관 관계를 확인
- "비정상성 데이터를 정상 데이터로 변환"하는 것은 ACF의 역할이 아님 (차분 등이 담당)
- 이동 평균으로 계절성 제거는 가능

**TF-IDF 해석**
- TF (Term Frequency): 특정 문서에서 등장한 단어 수
- IDF (Inverse Document Frequency): log(전체 문서 수 / 해당 단어가 등장한 문서 수)
- IDF가 역수(Inverse)이므로, 여러 문서에 등장하는 단어일수록 중요도가 낮아짐
- "특정 문서에만 자주 등장하는 단어가 중요한 단어"라는 것이 핵심
- 유사도가 높은 문서 쌍의 TF-IDF 값은 0에 가까워짐 (공통 단어가 많으므로 IDF가 낮아짐)
- TF-IDF로 검색 엔진에서 **순위 결정 가능**

**깁스 샘플링**
- 다변량 분포에서 조건부 확률을 이용해 반복 샘플링
- 반복할수록 표본의 **분포**가 모집단 분포에 수렴 (특정 값이 아님)
- 초기 데이터는 무작위이므로 **버린다** (burn-in period)
- 베이지안 통계, LDA 토픽 추정, MCMC 시뮬레이션에서 사용
- 다음 시험에서도 출제 가능성 있으므로 기본 개념 정리 권장

**비모수 검정**
- 모집단의 분포를 모를 때 사용
- **순위, 중앙값, 빈도**로 검정 (평균 X)
- 평균으로 검정하는 것은 **모수 검정** (분포를 알고 있을 때)
- 만-휘트니(Mann-Whitney) 검정은 비모수 검정의 대표 사례. "평균으로 검정한다"는 틀림

**상관계수 관련 복합 문제 (기억/니은/디귿 형태)**
- 핵심 포인트: 상관계수 값만으로는 **유의성**을 판단할 수 없음
- "유의하다"는 표현이 있으면 -> p-value(T-검정) 필요
- "강한 상관관계다"라는 표현이면 -> 상관계수 값으로 판단 가능
- "상관계수가 0이면 연관 없다" -> 비선형 관계가 있을 수 있으므로 틀림

</details>

**Q3.** ACF(자기상관함수)에 대한 설명으로 **틀린 것**은?

1. 현재 시점과 과거 시점 간의 상관관계를 확인한다
2. 시계열 데이터의 계절성 패턴을 식별하는 데 활용된다
3. 비정상성 데이터를 정상 데이터로 변환하는 역할을 한다
4. ARIMA 모형의 MA(이동평균) 차수를 결정하는 데 참고한다

<details>
<summary>정답 및 해설</summary>

**정답: (3)**

- (1) ACF는 시차(lag)별 자기상관을 측정
- (2) ACF 플롯에서 주기적 패턴이 보이면 계절성 존재
- (3) **틀림**. 비정상 → 정상 변환은 **차분(Differencing)**이 담당. ACF는 상관관계를 "확인"하는 도구이지 데이터를 "변환"하지 않음 (11회 출제)
- (4) ACF가 빠르게 감소하면 MA 차수 결정에 참고
</details>

**Q4.** 계층적 군집분석에 대한 설명으로 **옳은 것**은?

1. 미리 군집 수(K)를 지정해야 한다
2. 반복 과정에서 데이터가 다른 군집으로 이동할 수 있다
3. 한번 특정 군집에 속하면 변경이 불가능하다
4. K-means보다 대용량 데이터에 더 적합하다

<details>
<summary>정답 및 해설</summary>

**정답: (3)**

- (1) 군집 수를 미리 지정하는 것은 **K-means**. 계층적 군집분석은 덴드로그램에서 절단 높이로 군집 수를 결정
- (2) 반복 중 군집 이동 가능한 것은 **K-means**
- (3) 계층적 군집분석은 가까운 것끼리 순차적으로 묶어나가며, 한번 묶이면 **변경 불가** (군집 규모가 커질 뿐)
- (4) 계층적 군집분석은 O(n²) 이상의 복잡도로 대용량 데이터에는 **부적합**. K-means가 더 효율적
</details>

**Q5.** 다음 중 과적합을 방지하는 방법으로 **적절하지 않은 것**은?

1. 드롭아웃(Dropout)을 적용한다
2. 조기 종료(Early Stopping)를 사용한다
3. 규제(Regularization) 강도를 낮춘다
4. 학습 데이터를 증가시킨다

<details>
<summary>정답 및 해설</summary>

**정답: (3)**

- (1) 드롭아웃은 신경망에서 무작위로 노드를 비활성화하여 과적합 방지
- (2) 조기 종료는 검증 오차가 증가하기 시작할 때 학습을 멈춤
- (3) **부적절**. 규제 강도를 **높여야** 과적합 방지. 낮추면 오히려 과적합이 심해짐 (L1/L2 정규화의 람다 값을 키워야 함)
- (4) 학습 데이터가 많을수록 모델이 다양한 패턴을 학습하여 일반화 성능 향상
</details>

### 4과목: 빅데이터 결과 해석 (5문제)

**Q1.** 비모수 검정에 대한 설명으로 **옳은 것**은?

1. 모집단이 정규분포를 따를 때 사용한다
2. 만-휘트니 검정은 두 집단의 평균을 비교한다
3. 모집단의 분포를 모를 때 순위, 중앙값 등으로 검정한다
4. 모수 검정보다 항상 검정력이 높다

<details>
<summary>정답 및 해설</summary>

**정답: (3)**

- (1) 정규분포를 따를 때 = **모수 검정** (t검정, F검정 등)
- (2) 만-휘트니 검정은 **순위**로 검정. "평균으로 비교"는 **틀림** (11회 핵심 출제 포인트)
- (3) 비모수 검정은 분포 가정 없이 **순위, 중앙값, 빈도**로 검정
- (4) 모수 검정의 가정이 충족되면 모수 검정의 검정력이 더 높음. "항상"은 틀림
</details>

**Q2.** 피어슨 상관계수가 0인 두 변수에 대한 설명으로 **옳은 것**은?

1. 두 변수는 완전히 독립이다
2. 두 변수 사이에 어떤 관계도 없다
3. 두 변수 사이에 선형 관계가 없다
4. 두 변수의 공분산은 양수이다

<details>
<summary>정답 및 해설</summary>

**정답: (3)**

- (1) 상관계수 0 ≠ 독립. 비선형 관계(U자 형태 등)가 있어도 상관계수는 0일 수 있음
- (2) "어떤 관계도 없다"는 **틀림**. **선형** 관계가 없을 뿐, 비선형 관계는 존재 가능 (11회 출제)
- (3) 피어슨 상관계수는 **선형 관계**만 측정하므로, 0이면 선형 관계가 없다는 뜻
- (4) 상관계수 0이면 공분산도 0 (비례 관계)
</details>

**Q3.** 다음 중 **카토그램(Cartogram)**에 대한 설명으로 **옳은 것**은?

1. 계단형 색상 구간을 사용하여 지역별 값을 표현한다
2. 지도 위에 버블 크기로 값을 표현한다
3. 등고선처럼 동일한 값을 가진 지점을 연결한다
4. 면적을 왜곡하여 데이터 값의 크기를 강조한다

<details>
<summary>정답 및 해설</summary>

**정답: (4)**

- (1) 계단형 색상 구간 = **단계 구분도(Choropleth)**
- (2) 지도 위 버블 = **버블 플롯맵**
- (3) 등고선 = **등치선도**
- (4) 카토그램은 지도의 **면적을 왜곡**하여 데이터 값을 시각적으로 강조. 왜곡이 발생할 수 있다는 것이 핵심 특징
</details>

**Q4.** 회귀 분석에서 R² = 0.85일 때의 해석으로 **옳은 것**은?

1. 독립변수가 종속변수 변동의 85%를 설명한다
2. 예측 정확도가 85%이다
3. 상관계수가 0.85이다
4. 잔차의 분산이 85%이다

<details>
<summary>정답 및 해설</summary>

**정답: (1)**

- (1) R²(결정계수) = SSR/SST = 회귀 모형이 설명하는 변동의 비율. 0.85면 독립변수가 종속변수 변동의 **85%를 설명**
- (2) 예측 정확도와 R²는 다른 개념. R²는 설명력 지표
- (3) 상관계수 r = √R² = √0.85 ≈ 0.92 (같지 않음)
- (4) 잔차가 설명하는 비율은 1-R² = 15%
</details>

**Q5.** 분석 보고서의 **요약(Executive Summary)** 부분에 대한 설명으로 **가장 적절한 것**은?

1. 분석에 사용한 알고리즘과 파라미터를 상세히 기술한다

4. 분석 결과의 한계점과 향후 과제를 정리한다

<details>
<summary>정답 및 해설</summary>

- (2) Executive Summary는 의사결정자가 **가장 먼저 읽는** 부분으로, 핵심 발견과 권고 사항을 **간결하게** 제시해야 함
- (3) 데이터 수집/전처리 = 분석 방법 섹션
- (4) 한계점/향후 과제 = 결론 및 제언 섹션

## 1과목: 빅데이터 분석 기획

### 필수 암기 키워드

**DIKW 피라미드**: 데이터(객관적 사실) → 정보(패턴 인식) → 지식(의사결정) → 지혜(창의적 전략)

**암묵지-형식지 변환**: "공표연내" (공통화/표출화/연결화/내면화)
- 공통화: 암묵→암묵 | 표출화: 암묵→형식 | 연결화: 형식→형식 | 내면화: 형식→암묵

**DB 4대 특징**: "공통저변" (공용/통합/저장/변화)

**DB 설계 순서**: "개논물" (개념적→논리적→물리적)

**빅데이터 3V** (가트너 정의): Volume(규모), Variety(다양성), Velocity(속도)
- ⚠️ Value, Veracity는 3V에 포함 안 됨 (5V/7V 확장)

**데이터 단위**: 테라 이후 "페엑제요" (PB→EB→ZB→YB)

**빅데이터 활용 3대 요소**: "인자기" (인력, 자원, 기술)

**빅데이터가 만든 변화**: "전후양상"
| 이전 | 이후 |
|------|------|
| 표본 조사 | **전**수 조사 |
| 사전 처리 | 사**후** 처리 |
| 질 중심 | **양** 중심 |
| 인과 관계 | **상**관 관계 |

**가치 패러다임**: 디지털화 → 연결(커넥션) → 에이전시

**조직 구조**: "집기분"
| 집중 | 별도 전담 조직, 표준화/통합 관리 |
|------|------|
| 기능 | 각 부서가 직접 양성, 현업 이해도 높음 |
| 분산 | 분석 인력을 현업에 파견, **현업 빠르게 적용** |

**분석 매트릭스** (What/How):
| | How 앎 | How 모름 |
|---|---|---|
| What 앎 | **최적화** | **솔루션** |
| What 모름 | **통찰** | **발견** |

**CRISP-DM**: "업데데모평전" (업무이해→데이터이해→데이터준비→모델링→평가→전개)
- ⚠️ "모델 작성 및 평가"는 **모델링** 단계에서 수행

**빅데이터 분석 방법론 5단계**: 분석기획→데이터준비→데이터분석→시스템구현→평가/전개
- SOW: 비즈니스이해/범위설정 | WBS: 프로젝트 계획 수립 단계
- **위험 대응 4가지**: "회전완수" (회피/전이/완화/수용)

**PMBOK 10영역**: "범총이 의자에서 시원한 조리품"
(범위/총합/이해관계자/의사소통/자원/시간/원가/조달/리스크/품질)

**분석 거버넌스**: "시조프데마" (시스템/조직/프로세스/데이터/마인드육성)

**분석 준비도 6분야**: "IT문대기인파" (IT인프라/분석문화/분석데이터/분석기법/인력조직/분석업무)

**분석 성숙도**: 도입→활용→확산→최적화 (CMMI 기반)

**준비도-성숙도 매트릭스**: "도준정확" (시계 방향)
- 확산형 = 가장 높은 수준 (준비도 높+성숙도 높)

**데이터 거버넌스 구성**: "원조프로" (원칙/조직/프로세스)

**데이터 거버넌스 7대 원칙**: "책표투무감보준"
(책임성/표준화/투명성/무결성/감사가능성/보안성/준거성)

**ETL**: Extract(추출)→Transform(변환)→Load(적재)

**데이터 유형**:
| 정형 | 고정 스키마 (RDBMS, 엑셀) |
|------|------|
| 반정형 | 메타데이터 포함, **구조 변경 가능** (XML, JSON) |
| 비정형 | 틀 없음 (텍스트, 이미지, 영상) → NoSQL |

**데이터 3법**: "개정신" (개인정보보호법/정보통신망법/신용정보법)
- 개정 핵심 = **가명정보** 개념 도입
- 정보통신망법 개인정보 규정 → **개인정보보호법으로 이관**
- 신용정보법 → **마이데이터** 도입

**비식별화 5기법**: 가명처리/총계처리/삭제/마스킹/범주화
- ⚠️ 총계 처리 → 개인 단위 수치 계산 **불가**
- 세부: 교환법(Swapping)=가명, 라운딩/재배열=총계, 감추기(Suppression)=삭제

**프라이버시 보호 모델**: K-익명성 → L-다양성 → T-근접성 (보호 수준 상승)

**DW 4대 특성**: 주제지향성/통합성/시계열성/비휘발성

**개인정보→가명정보→익명정보**: 가명 = 추가정보 없이 식별 불가, 익명 = 절대 식별 불가

**기업 시스템 약어**: OLTP(거래)/OLAP(분석)/CRM(고객)/SCM(공급)/ERP(기업자원)/BI(통찰)/KMS(지식)

**AI 포함 관계**: AI ⊃ ML ⊃ DL
- 머신러닝 4종: 지도/비지도/준지도/강화
- 전이학습 = 사전학습 모델 재사용 | 파인튜닝 = 미세조정 | 지식증류 = 선생→학생

**데이터 품질 7기준**: 유효성/완전성/일관성/정확성/유일성/적시성/접근성
- ⚠️ 완전성 = 누락 없이 존재 (접근성과 혼동 주의)

### 기출 빈출 TOP 5

## 2과목: 빅데이터 탐색

### 필수 암기 키워드

**척도 비교**:
| 척도 | 순서 | 간격 | 절대0 | 연산 | 예시 |
|------|------|------|-------|------|------|
| 명목 | X | X | X | 분류만 | 혈액형, 성별 |
| 서열 | O | X | X | 대소 | 학점, 순위 |
| 등간 | O | O | X | +,- | 온도(섭씨) |
| 비율 | O | O | O | 사칙 | 키, 무게, 나이 |

- ⚠️ 등간 vs 비율 핵심 = **절대 영점 존재 여부**

**결측값 3유형**: MCAR(완전무작위)/MAR(무작위)/MNAR(비무작위)
- 핫덱 = 현재 데이터셋에서 대체 | 콜드덱 = 외부 출처에서 대체

**이상값 탐지 - 박스플롯** (IQR):
- IQR = Q3 - Q1
- 하한 = Q1 - 1.5*IQR | 상한 = Q3 + 1.5*IQR
- ⚠️ 박스플롯에서 **평균값은 알 수 없다** (가장 빈출 함정)
- ⚠️ 이상값은 "항상 제거"가 아님

**변수 선택 3방법**: 필터(통계적 점수)/래퍼(모델 학습 비교)/임베디드(학습 중 자동선택)
- 전진선택법: 하나씩 추가 | 후진제거법: 하나씩 제거 | 단계별: 추가+제거 번갈아

**차원 축소**:
| PCA | 분산 최대화, 비지도, 라벨 불필요 |
|-----|------|
| LDA | 클래스 분리 최대화, 지도, 라벨 필요 |

- PCA = "분산 최대화" 키워드 연결 ← 거의 매 시험 출제
- LSA = SVD로 문서-단어 행렬을 저차원 의미 공간으로 변환

**인코딩**:
- 레이블: 정수 변환 → 단점: **서열 부여 문제**
- 원핫: [1,0,0] 형태 → 단점: **메모리 증가**

**불균형 처리**: 오버샘플링(소수 늘림)/언더샘플링(다수 줄임)/SMOTE(합성 데이터 생성)

**공분산/상관계수** 핵심 낚시:
- 독립이면 공분산 0 → **맞음 (O)**
- 공분산 0이면 독립 → **틀림 (X)** (비선형 관계 가능)

**상관계수 3종 비교**:
| 피어슨 | **선형** 관계, 원래 값, 이상치에 **약함** |
|------|------|
| 스피어만 | **단조적** 관계, 순위 변환, 이상치에 **강함** |
| 켄달 | **순서 일치** 관계, 순위 쌍 비교, **소표본에 신뢰도 높음** |

**왜도** (평균/중앙값/최빈값 관계):
- 양의 왜도(오른쪽 꼬리 길): **최빈 < 중앙 < 평균**
- 음의 왜도(왼쪽 꼬리 길): **평균 < 중앙 < 최빈**

**Z-스코어**: Z = (X - μ) / σ | N(μ, σ²)에서 두 번째 = **분산**

**기대값/분산 계산**:
- E(aX + bY + c) = a·E(X) + b·E(Y) + c
- Var(aX + bY + c) = a²·Var(X) + b²·Var(Y) (상수 분산=0, 계수는 제곱)

**표본 추출** (가장 중요 비교):
| | 집락(군집) 추출 | 층화 추출 |
|---|---|---|
| 방법 | 군집 중 일부만 선택 | 모든 층에서 비례 추출 |
| 군집 간 | **동질적** | **이질적** |
| 군집 내 | **이질적** | **동질적** |

**확률분포 8종**:
| 이산 | 베르누이→(n번)→**이항**(np,np(1-p))→(n→∞)→**포아송**(λ=평균=분산) |
|------|------|
| 이산 | 이항→(비복원)→**초기하** (시행 독립 아님) |
| 연속 | **정규**→(모분산 모름)→**t**(꼬리 두꺼움)→(제곱합)→**카이제곱**→(비 비교)→**F** |
| 연속 | **지수분포** = 사건 간 대기시간 / **균일분포** = 동일 확률 |

- 카이제곱: 범주형 독립성 검정 | F: ANOVA(3개 이상 평균 비교) | 포아송 키워드: "단위 시간/공간당"

**중심극한정리(CLT)**: 모집단 분포 무관, 표본 평균은 정규분포 (n ≥ 30)
- 표본 평균의 분산 = σ²/n | 표준오차 = σ/√n

**1종/2종 오류**:
| | H₀ 참 | H₀ 거짓 |
|---|---|---|
| H₀ 기각 | **1종 오류 (α)** 무고한 유죄 | 올바른 기각 |
| H₀ 채택 | 올바른 채택 | **2종 오류 (β)** 범인 무죄 |
- 검정력 = 1 - β | α와 β는 **트레이드오프** | 검정은 **α에만 집중**

**데이터 변환 5종** (왜도 교정 강도순):
- 제곱근 < 로그 < 역수 < Box-Cox(λ 자동 결정)
- 로그: 오른쪽 꼬리 긴 분포, 0이하 불가 | Box-Cox: λ=0→로그, λ=0.5→제곱근

**표준화 vs 정규화**:
| Z-스코어 표준화 | 평균0, 표준편차1, 이상치에 상대적 강건 |
|------|------|
| 민맥스 정규화 | 0~1, 이상치에 **민감** |

**자연어 전처리 5단계**: 토큰화→불용어처리→정규화→어간추출(Stemming)→표제어추출(Lemmatization)

### 기출 빈출 TOP 5
1. 집락 추출 vs 층화 추출 (군집 내/간 동질성/이질성)
2. 박스플롯 해석 (IQR, 평균 알 수 없음)
3. PCA = 분산 최대화 / 차원 축소 기법 비교
4. 공분산 0 ≠ 독립 (매 시험 반복 출제)
5. 왜도 양수일 때 최빈<중앙<평균

## 3과목: 빅데이터 모델링

### 필수 암기 키워드

**과대적합 vs 과소적합**:
| | 과대적합 | 과소적합 |
|---|---|---|
| 복잡도 | 너무 복잡 | 너무 단순 |
| 편향 | 낮음 | 높음 |
| 분산 | 높음 | 낮음 |
| 훈련 성능 | 높음 | 낮음 |
| 검증 성능 | **낮음** | 낮음 |

- 과적합 = 과대적합 = 오버피팅 (같은 말)
- 과적합 방지: 가지치기/규제/드롭아웃/조기종료/데이터 증가

**데이터 분할**: 훈련(50~70%) / 검증(15~30%, 여러번) / 평가(10~20%, **1회만**)

**회귀분석**:
- y = wx + b | 최소제곱법으로 SSE 최소화
- R² = SSR/SST = 1 - SSE/SST (0~1, 1에 가까울수록 좋음)
- SST = SSR + SSE

**규제 회귀 비교**:
| 리지(Ridge) | L2, 가중치 **제곱합**, 0에 가깝게만 |
|------|------|
| 라쏘(Lasso) | L1, 가중치 **절대값합**, 0으로 만듦 → **변수 선택 효과** |
| 엘라스틱넷 | L1 + L2 결합 |

**선형회귀 4가정**: "선분정독" (선형성/등분산성/정규성/독립성)
- 선형성만 변수 간, 나머지 3개는 **잔차** 가정

**다중공선성**: 독립변수끼리 상관 높음 → **VIF ≥ 10이면 존재**
- 해결: 변수 제거/차원축소(PCA)/규제/변수선택

**회귀 검정**: 회귀계수 = **t검정** | 모형 전체 = **F검정**

**로지스틱 회귀**:
- 오즈 = 성공확률/실패확률
- 로짓 변환 = ln(오즈) → 선형화
- 시그모이드: 0~1 출력 → 분류
- 추정: **최대우도법** (최소제곱법 아님)

**의사결정나무**:
- **화이트박스** 모델 (해석 용이) ↔ 신경망 = 블랙박스
- 과적합 방지 = **가지치기**
- 지니지수 = 1 - Σ(pᵢ)² (CART) | 엔트로피 = -Σpᵢlog₂pᵢ (C4.5, ID3)
- ⚠️ 지니 = 0이면 완벽 순수

**의사결정나무 5종 비교**:
| ID3 | 엔트로피(정보이득) | **다지분할** | 범주형만 |
|-----|------|------|------|
| C4.5 | **정보이득비** | 다지분할 | 범주+연속, 결측치 처리 |
| C5.0 | 정보이득비 | 다지분할 | C4.5 개선, 속도 향상 |
| **CART** | **지니지수** | **이진분할** | 범주+연속, 가장 많이 사용 |
| CHAID | **카이제곱** | 다지분할 | 범주형, 통계적 유의성 기반 |

**차원의 저주**: 변수 너무 많으면 데이터 희박 → 성능 저하 → 해결: PCA/변수선택/라쏘

**인공신경망**:
- 파라미터(가중치, 편향) = 학습으로 **자동** 조정
- 하이퍼파라미터(K, 은닉층수, 학습률) = **사용자** 설정

**활성함수**:
| 시그모이드 | 0~1, 기울기 소실 발생 |
|------|------|
| tanh | -1~1, 소실 완화 |
| **ReLU** | 0 or 자기자신, **기울기 소실 해결** |
| 소프트맥스 | 다중분류, 확률 합=1 |

- ⚠️ ReLU = 기울기 소실 방지 + 비선형. **과적합 방지가 아님!**
- 이진분류→시그모이드 | 다중분류→소프트맥스 | 회귀→항등함수

**손실함수**: 회귀=MSE | 분류=Cross Entropy

**SVM**:
- 마진 최대화 → 초평면 찾기
- 서포트 벡터 = 초평면에 **가장 가까운** 데이터만 영향
- 커널 트릭 없으면 = 선형 분류기
- 소프트 마진 = 오류 허용 | 하드 마진 = 오류 불허

**연관분석**: "지신향"
| 지지도 | P(A∩B) |
|------|------|
| 신뢰도 | P(A∩B)/P(A) |
| 향상도 | P(A∩B)/(P(A)×P(B)) → >1 양의 상관, =1 독립, <1 음의 상관 |

**K-Means vs DBSCAN**:
| | K-Means | DBSCAN |
|---|---|---|
| 기반 | 거리 | **밀도** |
| 군집 수 | **사전 지정(K)** | 자동 |
| 이상치 | 민감 | **강건** |
| 최적 K | 엘보 메소드 | 불필요 |

**계층적 군집**: 덴드로그램에서 특정 높이로 자르면 군집 수 결정

**시계열 ARIMA(p,d,q)**:
- p=AR차수(PACF), d=차분횟수, q=MA차수(ACF)
- 정상성 가정 → 비정상 시 차분으로 정상화
- ⚠️ "항상 비정상성 가정" → **틀림**

**분해 시계열 4요인**: 추세/계절/순환/불규칙

**앙상블**: 배깅 = **분산** 감소 (독립 학습) | 부스팅 = **편향** 감소 (순차 보완)

**부스팅 4종 비교**:
| 랜덤포레스트 | **배깅**, 병렬, Level-wise, 안정적 |
|------|------|
| XGBoost | 부스팅, Level-wise, 높은 성능 |
| **LightGBM** | 부스팅, **Leaf-wise(수직)**, **매우 빠름** |
| **CatBoost** | 부스팅, **범주형 변수 자동 처리** |

**GMM (가우시안 혼합 모델)**: 확률 기반 군집화, EM 알고리즘, 타원형 군집 가능
- vs K-Means: K-Means=하나의 군집/구형/거리 | GMM=여러 군집 확률적/타원형/확률분포

**KNN**: K개 이웃 다수결 분류, **게으른 학습(Lazy Learning)** = 사전 훈련 없음

**오토인코더**: 인코더(압축)→잠재공간→디코더(복원), **비지도 학습**

### 기출 빈출 TOP 5
1. 의사결정나무 (지니지수 계산, 가지치기, 화이트박스)
2. 연관분석 지지도/신뢰도/향상도 계산
3. K-Means vs DBSCAN 비교
4. 리지(L2) vs 라쏘(L1) - 변수 선택 효과
5. 활성함수(ReLU = 기울기 소실 방지, 과적합 방지 아님)

## 4과목: 빅데이터 결과해석

### 필수 암기 키워드

**혼동행렬**:
```
              예측 Positive    예측 Negative
실제 Positive |   TP          |   FN         |
실제 Negative |   FP          |   TN         |
```
- True/False = 맞았냐/틀렸냐 | Positive/Negative = 모델이 뭐라 했냐

**분류 평가지표 공식**:
| 정확도 | (TP+TN)/전체 |
|------|------|
| **정밀도** | TP/(TP+**FP**) — 양성 예측 중 진짜 |
| **재현율** | TP/(TP+**FN**) — 실제 양성 중 찾은 비율 |
| 특이도 | TN/(TN+FP) |
| **F1** | 2*(정밀도*재현율)/(정밀도+재현율) = **조화평균** |

- 재현율 = 민감도 = TPR = 히트레이트 (전부 같은 말!)
- 정밀도와 재현율은 **트레이드오프**

**ROC/AUC**:
- ROC: X축=FPR(1-특이도), Y축=TPR(민감도)
- AUC 범위: **0.5~1** (0.5=찍기, 1=완벽)

**회귀 평가지표**:
| SSE | Σ(실제-예측)² |
|-----|------|
| MSE | SSE/n |
| MAE | Σ|실제-예측|/n |
| RMSE | √MSE |
| MAPE | Σ(|실제-예측|/실제)×**100**/n ← ⚠️ 100 곱함! |

- R² = SSR/SST (0~1) | 다중회귀 → **수정된 R²** 사용

**군집 평가**:
- 실루엣 계수: 범위 **-1~1** (1에 가까울수록 좋음)
- 엘보 메소드: K를 늘려가며 WCSS 계산 → 꺾이는 지점 = 최적 K

**교차 검증**:
| 홀드아웃 | 1회 분할, 간단 |
|------|------|
| K-Fold | K번 반복, 가장 많이 사용 |
| LOOCV | 1개만 검증, 데이터 적을 때 |
| 부트스트래핑 | 복원추출, OOB 활용 |

**하이퍼파라미터 튜닝**:
- 그리드 서치 = 모든 조합 **체계적** 탐색
- 랜덤 서치 = 무작위 탐색
- 베이지안 최적화 = 과거 결과 기반

**경사하강법 옵티마이저**:
- SGD: 소배치, 빠르지만 지역최소값 위험
- 모멘텀: 관성으로 지역극소값 뛰어넘기
- **Adam**: 모멘텀+RMSProp, 가장 많이 사용

**p-value 해석**:
- p < 0.05 → 귀무가설 **기각** (유의)
- p > 0.05 → 귀무가설 **채택** (유의하지 않음)
- ⚠️ p-value ≠ "귀무가설이 참일 확률" (흔한 오해! 시험 함정)
- 정확한 의미: H₀ 참 가정 시 이만큼 극단적 결과가 나올 확률

**검정 종류**:
- t검정: 1~2집단 **평균** 비교
- F검정: 두 집단 **분산** 비교
- ANOVA: **3개 이상** 집단 평균 비교

**QQ Plot**: 점이 45도 대각선 위 → 정규분포

**조기 종료**: 검증 오차 증가 시 학습 중단 → 과적합 방지

**시각화**:
| 시간 | 선그래프, 영역차트 |
|------|------|
| 공간 | 단계구분도(계단형 색상), 카토그램(**왜곡**) |
| 관계 | 산점도, 버블차트, 히트맵 |
| 분포 | 파이차트, 박스플롯, 트리맵 |

- ⚠️ 파이차트 = 비율용, **관계 시각화에 부적절**
- ⚠️ 단계구분도 = 연속형 데이터를 "정확하게" 표현 **못함** (계단형)

**인포그래픽 vs 데이터 시각화**:
- 인포그래픽 = **설득형**, 가공 데이터 | 시각화 = **정보형**, 로우 데이터
- ⚠️ 둘은 **동일 개념이 아님**

**오즈비(Odds Ratio) 해석** (로지스틱 회귀):
- OR = e^β | β>0 → OR>1(발생 증가) | β=0 → OR=1(영향 없음) | β<0 → OR<1(발생 감소)

**잔차분석** (회귀 가정 "선분정독" 진단):
| 선형성 | 잔차 vs 예측값 → 패턴 없어야 함 |
|------|------|
| 등분산성 | 잔차 vs 예측값 → 나팔 형태면 위반 |
| 정규성 | **QQ Plot**, 샤피로-윌크 검정 |
| 독립성 | **더빈-왓슨(Durbin-Watson)** 검정 |

**AIC/BIC** (모델 선택 기준): 둘 다 **작을수록 좋다**
- AIC = -2*로그우도 + 2k (예측 성능 중시)
- BIC = -2*로그우도 + ln(n)*k (더 **보수적**, 단순 모델 선호)

**신뢰구간 vs 예측구간**: 예측구간이 항상 **더 넓다** (개별 관측 변동성 포함)

**회귀 분석 출력 해석**:
- 자유도 + 1 = 데이터 개수
- F검정 p-value 작음 → 모형 유의
- 개별 변수 p-value > 0.05 → 해당 변수 유의하지 않음

### 기출 빈출 TOP 5
1. 혼동행렬 계산 (정밀도/재현율/F1) — 매회 출제
2. ROC/AUC (가로축=FPR, AUC 0.5~1)
3. 과대적합 학습곡선 (훈련 감소 + 검증 증가)
4. 리지 vs 라쏘 수식 판별 + 희소해
5. p-value 해석 (회귀/로지스틱 결과)

## 과목 공통 혼동 주의

### 용어 혼동 정리

| 혼동 쌍 | 핵심 차이 |
|---------|---------|
| 공분산 0 vs 독립 | 공분산 0 → **독립 아닐 수 있음** (비선형 관계) |
| 과적합 vs 과소적합 | 과적합 = 훈련 높음+검증 낮음 / 과소적합 = 둘 다 낮음 |
| 파라미터 vs 하이퍼파라미터 | 파라미터=자동학습(가중치) / 하이퍼파라미터=사용자설정(K,학습률) |
| 리지(L2) vs 라쏘(L1) | 리지=0에 가깝게 / 라쏘=**0으로 만듦(변수 선택)** |
| PCA vs LDA | PCA=비지도,분산최대 / LDA=지도,클래스분리 |
| 집락추출 vs 층화추출 | 집락=군집간 **동질** / 층화=군집간 **이질** |
| 피어슨 vs 스피어만 | 피어슨=이상치 약함 / 스피어만=이상치 강함 |
| 배깅 vs 부스팅 | 배깅=분산 감소 / 부스팅=편향 감소 |
| ReLU 역할 | 기울기 소실 방지 O, **과적합 방지 X** |
| 정밀도(1과목) vs 정밀도(4과목) | 1과목=반복 시 동일 결과 / 4과목=TP/(TP+FP) |
| 등간 vs 비율 | 절대 영점 유무 (온도=등간, 무게=비율) |

### 절대 표현 함정
- "반드시", "항상", "절대" → 높은 확률로 **틀린 보기**
- 예: "이상값은 항상 제거" → X / "인공지능은 학습 없이 대응" → X

### 자주 나오는 공식 한줄 정리
```
Z = (X-μ)/σ                    IQR = Q3-Q1
R² = SSR/SST = 1-SSE/SST       이항분포: 평균=np, 분산=np(1-p)
지니 = 1-Σ(pᵢ)²                VIF ≥ 10 → 다중공선성
F1 = 2*정밀도*재현율/(정밀도+재현율)  오즈 = p/(1-p)
향상도 = P(A∩B)/(P(A)×P(B))    실루엣 = (b-a)/max(a,b)
OR = e^β (오즈비)                AIC/BIC = 작을수록 좋음
검정력 = 1-β                     포아송: 평균=분산=λ
MinMax = (X-Xmin)/(Xmax-Xmin)   더빈왓슨 → 독립성 검정
```
